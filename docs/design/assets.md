# 资产

用户生成的作品和上传的素材。布局：侧栏 → 文件夹（SecondaryNav，宽 `secondary-width`）→ 资产列表。

## 列表

- 顶部：标题与总数，右侧搜索（匹配提示词和文件名）与「上传」。
- 筛选：来源「全部 / 生成 / 上传」+ 类型下拉；「生成」下可切换「画廊 / 批次」。
- 画廊：按日期分组的四列 MediaTile 瀑布流。批次：与生成记录相同的 RunGroup。
- 悬停：选择圈、下载、更多、「用于创作」。

## 多选

- 选中项加 2px `ink` 描边与对勾；底部出现 SelectionBar：移动到、下载、删除、用于创作。
- 「用于创作」打开菜单：图片（参考图）、视频（参考素材）、批量（新建一组）、对话（附件）。超出目标上限时只加入前面的，并提示数量。

## 文件夹

- 二级栏：全部资产、未归类，下面是文件夹列表与新建按钮。每个资产只属于一个文件夹，只有一层。
- 放入方式：拖到左侧文件夹上（目标加黑框并显示数量），或「移动到」菜单（可搜索、可新建并移入，当前位置不可选）。完成后 Toast「已移动 5 项到『模特图』」，可撤销、可查看。
- 文件夹「…」：重命名、置顶、下载全部、删除文件夹。删除只删文件夹，资产回到「未归类」。
- 在文件夹里上传，文件直接进入该文件夹。

## 详情

- 全屏 MediaViewer：大图、同批次缩略图、右侧 MediaInfoPanel（提示词、参考素材、参数、文件夹、来源、大小、时间）。
- 顶部：下载、更多（发布为灵感案例、删除）、「用于创作」。

## 状态

- 空资产、搜索无结果、空文件夹：EmptyState，给出下一步。
- 上传：真实进度；失败格子写文件名与原因（格式不支持、超过 20 MB）。上传限制：JPG / PNG / WebP，单个 20 MB。
- 整页可拖入上传。删除先 ConfirmDialog。读取失败给「重试」。

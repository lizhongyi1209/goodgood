# 创作页

图片、视频、批量共用一套布局：左侧 SettingsPanel（宽 `panel-width`），右侧生成记录。两边各自滚动，面板外壳与底部 GenerateButton 完全一致，只有字段不同。

## 图片

- 字段：模型 → 参考图 → 提示词 → 比例 + 分辨率 → 数量 → 质量（仅 GPT Image）。
- 模型：Nano Banana 2.1（1K / 2K / 4K，参考图最多 10 张）、GPT Image 2.5 Sunburst、GPT Image 2.5 Flare。

## 视频

- 字段：模型 → 生成方式（ModeGrid）→ 素材 → 提示词 → 比例 + 分辨率 → 时长 → 生成音频。
- 模型：Seedance 2.5。全能参考：图片 30、视频 10、音频 10。视频编辑：源视频 + 1–5 张参考图。视频延长：源视频 + 方向 + 延长时长。编辑与延长的比例跟随源视频。
- 分辨率 480p / 720p，时长 4–30 秒。以上参数上线前以 BytePlus 控制台为准。

## 批量

- 字段：模型 → 参考图组（GroupCard）→ 匹配方式 → 提示词 → 比例 + 分辨率 → 每组张数。
- 全量匹配：各组两两组合，组数 = 各组张数相乘。顺序匹配：按编号一一配对，各组张数须相同；只有 1 张的组用于每一组。
- 提示词里用组名指代每组图片；改组名时提示词同步更新。
- 单次上限 200 组；空组、张数不一致、超出上限时生成按钮不可用，并在匹配方式下说明原因。
- 生成按钮写总张数和总价：「生成 50 张 ⚡1000」。

## 生成记录

- 每次生成一组 RunGroup，最新在上，组间 `space-8`；批量组带进度条，默认只显示两行。
- 结果见 MediaTile。失败的格子原位重试；批量可「全部重试」「只看失败」。
- 中途积分不足时批量暂停，已完成的保留，提示「充值并继续」。
- 往下翻看旧记录时有新生成，顶部出现「新的生成已开始」。

## 异常

- 素材上传失败或不符合要求：格子变虚线框，下方 InlineNotice 写实际值、上限和办法。
- 积分不足：生成按钮上方出现 `accent-soft` 提示条（需要多少、余额多少、充值），按钮不可用。
- 缺少必填项：点生成后才提示，字段加 `ink` 描边，下方一行说明。
- 提示词或素材未通过审核：该组不显示结果，写明「未扣除积分」，给「修改提示词」或「更换素材」。
- 网络断开：底部 Toast「正在重新连接…」，已提交的生成不受影响。

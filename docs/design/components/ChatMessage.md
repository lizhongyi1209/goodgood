# ChatMessage

对话中的消息。

## 规格
- 用户：靠右，`soft` 底，18px 圆角，`prompt` 字号；附件在气泡上方；下方复制、编辑。
- 回答：无气泡，上方 16px 模型标识 + 模型名 `caption`；正文 `prompt`；下方复制、重新回答。
- 提示词块：`soft` 底、`radius-lg`，标题「提示词」+「复制」「去生成图片 / 视频」（白底按钮）。
- 视频时间段：`soft` 底、`radius-xs` 的可点按钮，跳到视频对应位置。
- 切换模型：居中分隔线「已切换到 …」。

## 状态
- 回答中：末尾光标，输入面板显示停止。停止后保留已生成部分，可继续或重新回答。
- 失败或审核未通过：原位虚线框说明，写明是否扣积分。

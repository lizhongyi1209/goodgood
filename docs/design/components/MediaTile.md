# MediaTile

所有作品与素材格子：生成记录、灵感、资产共用。

## 规格
- 保持真实比例，`radius-md`。时长、编号、来源用 `badge` 角标。
- 悬停：叠一层 `media-hover`，右上 32px 白色方按钮（`radius-item`）。按场景加一个主操作：记录无、灵感「做同款」、资产「用于创作」。
- 资产可多选：左上 22px 选择圈；选中后对勾 + 2px `ink` 内描边。
- 可在下方加一行 `caption` 说明（批量组合「模特 4 · 服装 4」）。

## 状态
- 生成中 / 上传中：`soft` 底 + 加载图标；上传有真实进度时底部画进度条。
- 失败：1.5px 虚线框，写原因和是否退回积分；可重试给「重试」，审核未通过给「修改提示词」。

## 行为
- 点击打开 MediaViewer。视频悬停静音播放。
- 触屏（hover: none）隐藏悬停主操作和放大按钮，点按格子打开预览；预览内保留主操作。失败状态的重试按钮仍可用。

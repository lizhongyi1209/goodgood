# GroupCard

批量生成的一个参考图组。

## 规格
- 1px `line`、`radius-lg`，内边距 10px 12px 12px。
- 头部：组名 13px 600、张数 `caption`、只有 1 张时标「每组都用」，右侧「…」。
- 素材行：最多 3 张 + 「+N」+ 添加格；都用 ReferenceThumb 尺寸。

## 状态
- 改名：组名变输入框；下方说明提示词里的组名会同步更新。
- 有图上传失败：张数旁写失败数，失败格子可点重试，失败的图不参与生成。
- 空组：只显示添加格与一行说明，生成按钮不可用。

## 「…」菜单
- 重命名、管理图片和顺序、复制这一组、上移、下移、清空图片（可撤销）、删除这一组（有图时确认；只剩一组时不可用）。

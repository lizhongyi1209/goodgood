# InlineNotice

在出问题的位置就地说明。

## 变体
- 输入面板：一行，生成按钮左侧，图标 + 文字 + 可选 24px `soft` 按钮。
- 面板提示块：`soft` 底、`radius-md`、内边距 10px 12px，图标 + 文字 + 下划线文字按钮；两个以上按钮时换到下一行。
- 积分不足：`accent-soft` 底、`accent` 字，实心闪电 + 「本次需要 N，余额 M」+「充值」。
- 字段错误：字段下方一行 `caption` + 图标，字段本身加 `ink` 描边。

## 规则
- 只在触到限制或出错时出现；写实际值、上限和办法。不用红色。
- 同一处只显示一条，选最阻碍操作的那条。

# ReferenceThumb

所有素材格子：已添加、空格子、添加按钮。

## 规格
- 一律 `reference-slot` 见方、`radius-lg`。
- 已添加：`fill-active` 底，显示图片或视频首帧；音频显示波形图标。
- 空格子与添加按钮：`soft` 底，空格子写名称（首帧、尾帧、源视频）。
- 角标：编号左下（图1、视1、音1，可在提示词里引用），时长左上；`badge` 底白字、`radius-xs`。
- 移除：右上 18px 黑色圆形，悬停或聚焦时出现，触屏常显。

## 状态
- 上传中：中央加载图标。上传失败：1.5px 虚线框 + 重试图标，点击重试。不可用：虚线框 + 提示图标，原因见 InlineNotice。

## 实现
- 共享 `useReferenceIntake`：拖入、粘贴、链接、从资产选择、校验、上限、上传与重试。

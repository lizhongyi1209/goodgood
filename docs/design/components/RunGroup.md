# RunGroup

生成记录里的一组：一次生成或一次批量。

## 规格
- 头部：提示词单行省略；下一行参数摘要 `caption`、`muted`；右侧全部下载、复用设置、更多。
- 结果网格间距 8px（带说明时行距 12px）；组与组之间 `space-8`。
- 批量组：头部下方 160px 进度条 +「正在生成 18 / 50」；默认显示两行，下方「查看全部 50 张」。

## 状态
- 部分失败：摘要里写「1 张失败，已退回 20 积分」；批量加「全部重试」「只看失败」。
- 暂停（积分不足）：进度条变 `muted`，下方积分提示条「充值并继续」，旁边「取消剩余」。
- 整组被拒：不显示格子，换成虚线框说明，写明未扣积分。

# 对话

用模型分析图片和视频、写提示词。布局：侧栏 → 历史对话（SecondaryNav，宽 `secondary-width`）→ 对话区。消息与输入面板宽不超过 `chat-max`，居中。

## 新对话

- 居中标题「想聊点什么？」（`display`），下方 Composer（对话版）与三个起手建议。

## 消息

- 见 ChatMessage。用户消息靠右灰底气泡；回答无气泡，上方标出模型名。
- 回答里的提示词放进提示词块，带「复制」和「去生成图片 / 视频」。
- 视频回答里的时间段可点，跳到视频对应位置。
- 中途切换模型时插入一条分隔线：「已切换到 GPT 6 Astra」。
- 消息贴底显示，最新的在最下面。

## 输入面板

- Composer 对话版：左下「+」与模型选择，右下发送；回答中发送变为停止。
- 「+」打开 AddReferenceMenu（上传图片或视频、从资产选择、从链接加载）；整个面板可拖入文件。
- 模型菜单每项只写名称和能力（可分析图片 / 图片和视频），不写价格。
- 当前模型不支持附件时不自动换模型，给「切换到…」和「移除」两个选择。

## 历史

- 按「今天 / 昨天 / 7 天内」分组；悬停显示「…」：重命名、置顶、删除（需确认）。
- 搜索同时匹配标题和消息内容，高亮关键词。

## 异常

- 停止回答：保留已生成部分，可继续或重新回答。
- 回答失败：原位虚线框写原因，说明是否扣积分，给「重试」。
- 内容未通过审核：不显示回答，写明未扣积分。
- 对话过长：提醒一次，可「带上摘要开新对话」。
- 网络断开：Toast 提示，恢复后自动重发。

## 范围与验收

- 要做：新增 `/credits` 积分记录页；桌面积分余额和移动端积分胶囊成为入口；展示可用/预留余额、全部/消费/获得/退回筛选和稳定分页。
- 要做：服务端将账本投影为用户可理解的业务记录。一次生成只显示一条：预留中为处理中，结算为已消费，释放为未扣除；退款和积分获得独立显示。
- 要做：记录显示模型、分辨率、张数、提示词摘要、时间与积分变化；成功生成可跳转到首张可见结果。
- 不做：充值、支付、钱包、导出、日期搜索、历史价格推测或计费启用前生成记录回填。
- 验收点：仅当前 owner 可读；不暴露账户/账本/支付/provider 内部标识；分页倒序无重复；成功生成不因 reserve/settle 显示成双倍扣费；加载、空、失败、重试和窄屏完整。
- 验收点：进入和离开记录页不清空草稿、项目或运行中的生成；浏览器前进/后退与直接刷新保持 `/credits` 语义。
- 决策影响：不改变已确认决策，无需 ADR。它是现有积分账本的只读用户投影，继续保持客户支付和钱包 UI 缺席。
- 授权边界：本地实现与验证；未授权合并、推送、真实 provider 请求或生产发布。

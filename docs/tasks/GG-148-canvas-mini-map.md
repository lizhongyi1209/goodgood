# GG-148 — 画布地图与缩放入口排版

- 状态：本地界面已修改，待站长手动验收；沿用 `F:/goodgood-worktrees/GG-116` 当前分支，未提交、不切分支、不部署。
- 请求：参考截图在 `/canvas` 左下角加入地图，收敛百分比的字号、字重与颜色，去掉百分比右侧图标。
- 决策：沿用 React Flow 内置 `MiniMap`，在 [ADR 0108](../decisions/0108-standalone-canvas-image-generation.md) 补充。地图默认展开，可用百分比左侧地图按钮收起/展开；地图操作直接驱动现有画布视口。

## 范围与验收

- 地图位于左下角百分比控制上方，以浅灰节点轮廓、白底轻描边展示画布内容和当前视口。可在地图上拖动定位、滚轮缩放，不新增网格、示例节点或持久化。
- 地图按钮有可访问名称与展开状态。百分比按钮保持打开原 10%–800% 菜单的能力，右侧不再显示下拉箭头，字号和字重更接近参考图的轻量工具栏。
- 窄屏继续让开底部生成输入区；地图展开/收起不影响图片拖动、缩放或生成。

## 验证与后续

已使用项目当前版本 `@xyflow/react` 自带的 MiniMap 和现有 ZoomSelect/Popover。官方 MiniMap 的 `pannable`、`zoomable` 驱动现有视口；通过一个共享底部偏移让地图与百分比在窄屏一起避开输入区。站长持续要求修改后不复测，本轮未运行自动测试或浏览器检查；由站长在现有 5173 `/canvas` 手动查看地图的位置、节点和视口同步、地图开关、百分比菜单与窄屏避让。未触发真实上传或付费生成，不替换 32131 或生产应用。

站长随后要求地图内清楚标出当前画面范围。沿用 MiniMap 自带视口蒙层，将画面外区域调浅，并给当前视口矩形设置 1.5px 中灰轮廓；拖动或缩放画布时由 React Flow 自动更新边界。按要求未复测，待站长手动查看。

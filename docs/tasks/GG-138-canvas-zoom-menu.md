## 范围与验收

- 画布初始缩放为 100%，允许 10%–800%；当前百分比随画布实际缩放实时更新。
- 左下角百分比打开菜单。顶部可以输入百分比，回车或离开输入框后应用，并限制在 10%–800%。
- 菜单有放大、缩小、适应屏幕，以及快速 50% 和 100%；不提供快速 800%。
- 菜单和顶部按钮的「适合屏幕」最多放大到 100%；单张小图不会先被放大填屏，再切到 50% 时产生突兀落差。50% 仍是画布绝对缩放比例。
- 菜单使用界面一致的白底黑字；点击菜单外关闭。
- 保持纯白画布，缩放控件在窄屏避开底部输入区。图片初始尺寸在桌面上限为 238×320 CSS 像素，窄屏再按屏幕宽高限制，避免 100% 初始视口中的图片过大；用户后续仍可自由缩放图片。

## 实施与验证

复用 React Flow 的视口 API 与现有 shadcn Button/Input/Popover，替换原固定级别 `ZoomSelect`。`CanvasWorkspace` 初始视口为 1、边界为 0.1–8，菜单放在左下角；窄屏沿用输入区避让。浮层采用白底、黑字、浅灰边框和浅色悬停；点击浮层或入口外的区域会关闭菜单。图片初始尺寸保留桌面 238×320 上限，窄屏进一步限制为视口宽度的 58% 和高度的 36%，保留原始比例。菜单与顶部的 `fitView` 均传入 `maxZoom: 1`，自动拟合不会超过 100%；输入值取整、限制在有效范围，滚轮缩放时显示值从视口状态读取。站长明确要求本次及后续改动不复测，由站长自行手动验收；本次未运行自动测试或浏览器检查，未替换 32131 或部署生产。

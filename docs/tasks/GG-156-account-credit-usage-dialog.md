# GG-156 — 头像菜单积分用量弹框

- 状态：本地界面已修改；待站长手动验收，未提交、未部署。
- 日期 / 工作区：2026-09-28；`F:/goodgood-worktrees/GG-116`，`feature/GG-116-asset-history-actions`。
- 用户需求：大厅头像菜单“积分余额”改为可点击的“积分”；点击展示参考截图的账户管理式页面弹框与用量明细；移走左栏积分记录入口；不显示“退回”日志。
- 决策：[ADR 0112](../decisions/0112-account-credit-usage-dialog.md)。

## 范围与验收

- 在桌面与手机头像菜单提供可键盘操作的积分入口，显示余额并打开页面内弹框；关闭回到原页面且不清空创作。
- 弹框为灰白账户侧栏 + 用量主区，展示周期消耗、状态、日期和积分变化；空、加载、错误、分页保持原能力。
- 全部/消费/获得筛选中排除预留释放与退回业务记录；不删除 `credit_ledger_entries`，不改变余额、原始账本或内部审计。
- 旧 `/credits` 深链接继续可访问，侧栏不再出现积分入口。

## 实现与证据

- `app/page.tsx`：移除侧栏积分记录按钮，将桌面与手机头像菜单的积分行改为可操作项；手机顶部余额也打开同一弹框，旧 `/credits` 分支保留。
- `features/billing/credit-usage-dialog.tsx`、`credit-activity-view.tsx`、`app/globals.css`：复用 shadcn Dialog/Select 与现有 owner-scoped 只读接口；账户导航、用量标题、周期汇总、四列明细表、加载/空/错误/分页均在弹框内。释放和退款在前端可见投影过滤；读取下一游标补足可见行。
- 授权边界：没有数据库写入、财务账本删除、余额更改、生产部署或新的依赖。32131 仍使用 GG-155 运行检查点，GG-156 只需 5173 界面热更新。
- 静态审阅：核对积分入口、弹框开关、过滤状态与游标拼接、窄屏滚动及相关文档。按站长要求不运行测试、构建或浏览器复测。

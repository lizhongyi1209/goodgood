# GG-206 · 画布连线持续悬停保持亮蓝

- 请求：修复鼠标持续停留在线条上时，亮蓝反馈消失。
- 状态：GG-116 本地源码已修改，待站长手动验收；未提交、未部署。
- 决策关系：修复 GG-200 已确认的悬停行为，不改变颜色、线型、延时或产品方向，无需新 ADR。

## 根因与实现

GG-200 仅使用 SVG 边的 CSS `:hover`。停留一秒后，居中剪刀按钮出现在鼠标位置；该按钮是 React Flow 外的兄弟元素，覆盖鼠标后 SVG 边失去 `:hover`，可见线恢复灰色。

在现有边进入/退出事件中，通过 DOM ref 为当前单条边设置临时 `data-canvas-edge-hovered`。线条与对应剪刀按钮共享该状态，线→按钮和按钮→同线均保留亮蓝。离开两者、切换到另一条边、点击空白、按钮失焦/删除、边被其他流程移除或组件卸载时清理。沿线移动继续复用原 ref 和 DOM 定位，不新增指针移动的 React 状态、不修改图数据、不触发项目保存。

修改 `features/canvas/canvas-workspace.tsx` 和 `canvas-workspace.module.css`，保留 `#1687ff`、120ms 颜色过渡、宽命中区、一秒剪刀显现、圆心贴线、流动虚线及删除数据路径。

## 验收与交接

- 在线条上停留超过一秒，剪刀出现后继续亮蓝，静止鼠标不熄灭。
- 沿线移动或停在剪刀上仍亮蓝，按钮仍随曲线最近点定位。
- 提前移开不出现剪刀；移到空白/其他节点/另一条线后旧线立即恢复，不残留按钮或高亮。
- 剪刀点击、键盘删除、节点删除、离开画布与减少动态效果保持原有行为。

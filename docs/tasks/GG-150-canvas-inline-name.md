- 状态：本地界面已修改，待站长手动验收；沿用 `F:/goodgood-worktrees/GG-116` 当前分支，未提交、不切分支、不部署。
- 请求：G 项目图标旁展示画布名字，鼠标悬停时给出可编辑样式，并支持修改名称。
- 决策：见 [ADR 0108 补充](../decisions/0108-standalone-canvas-image-generation.md)。当前画布布局尚不保存，名称随当前页面临时存在，不创建新画布文档或后端接口。

## 范围与验收

- 默认名称为「未命名画布」，位于 G 图标与右侧积分之间；长名称单行省略，窄屏仍保留积分位置。
- 悬停名称出现浅灰底与文本编辑光标，点击后原位输入。回车或失焦确认，Esc 取消；空白名称回退默认值。
- G 图标点击的「主页」菜单不改，名称编辑不上传、生成或保存画布布局。
- 站长追加：G 图标缩至 26px，名称紧邻图标并处于同一视觉高度；悬停用文本编辑光标，不显示铅笔；输入框宽度随名称变化，不在点击后突然变宽；最多 20 个中文字符。
- 站长追加：进入编辑态时，去掉输入框外侧的黑色焦点边框；用浅灰底和文字光标表达编辑状态。

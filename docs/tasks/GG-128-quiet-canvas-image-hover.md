# GG-128 — 画布图片轻量悬停

- 状态：本地实现与门禁完成，待站长手动浏览器验收；未部署。仅在 `F:/goodgood-worktrees/GG-116` 的 `feature/GG-116-asset-history-actions` 分支开发，未切分支。
- 基线：GG-127 `c396e01`；5173 热更新预览和 32131 已验证 Web 已运行。
- 请求：画布图片悬停时删掉覆盖在图片上的功能，只显示轻微悬停状态。
- 决策：[ADR 0109](../decisions/0109-quiet-canvas-image-hover.md) 取代 GG-126 的节点悬停操作设计。

## 验收

- 本地图片与生成结果图片悬停时均仅有浅灰遮罩，不出现图上按钮、标题或菜单；选中、焦点和触控也不常驻原按钮。
- 本地拖放、文件选择、节点移动与选中、结果图片详情、输入区单独的参考图选择和失败重试仍可用。
- 删除本地节点专用预览、加入参考、移除入口及其死代码；不触发真实上传或付费生成。

## 实现与验证

- 本地图片节点移除查看大图、用作参考、移除按钮及专用预览弹框；生成结果保留点击资产详情。两类图片节点共用约 4% 黑色的轻遮罩，覆盖层不接收指针事件；失败和等待中的节点仍按原状态显示。
- 保留 React Flow 节点选择与拖动；键盘删除本地节点时回收对象 URL。输入区的独立参考图选择与失败重试仍在。
- 定向画布测试 5/5，文档契约测试 8/8；`npm run check:local` 590 项 / 567 通过 / 23 跳过 / 0 失败，Lint 0 错误、110 条既有警告；5173 `/canvas` HTTP 200。首次完整门禁暴露 CURRENT_STATE/BACKLOG 行数与 ADR 索引文档约束，修正后完整重跑通过。
- 未进行浏览器验收、真实上传、付费生成、32131 检查点替换或生产部署。下一步由站长刷新现有 5173 `/canvas`，检查本地图片和生成图的悬停状态与保留交互。

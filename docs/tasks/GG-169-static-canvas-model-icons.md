# GG-169 — 画布模型图标本地静态化

- 状态：GG-116 未提交工作区已修改，待站长手动验收；未部署。
- 请求：将正在使用的画布模型图标改为本地静态文件，缓解 `/canvas` 刷新慢。
- 决策：[ADR 0113](../decisions/0113-static-canvas-model-icons.md) 取代 GG-142 的 React 包导入方式；模型、图标形状和菜单交互不变。

## 依据与范围

- 诊断时，热缓存的 `/canvas` HTML 约 37 ms，`/assets` 约 116 ms；画布独有的 `@lobehub/icons` 浏览器响应 `content-length` 为 31,025,566 字节，React Flow 约 1,327,136 字节。刷新慢的完整登录态耗时尚未测量，不能把全部延迟归因于图标包。
- 画布代码只取 `NanoBanana` 与 `OpenAI` 两个单色图标。复用现有 `public/model-icons/openai.svg`，把已安装的 `@lobehub/icons-static-svg/icons/nanobanana.svg` 复制到同目录；两个 SVG 对应原 React 组件路径。模型列表仍以稳定模型 ID 决定图标。
- 菜单图标保持 16×16、装饰性空 `alt`、不收缩；不改变标题、报价、选择、生成或其他画布功能。不删除当前 npm 依赖，避免扩大本次包锁改动。

## 验证与后续

按站长要求，改动后不运行自动测试、构建或浏览器复测；仅做静态文件和差异检查。站长在 5173 手动刷新 `/canvas`，观察加载耗时与模型菜单图标外观。该改动移除画布图标包请求，不能消除 React Flow 或开发环境冷编译成本。

## 下一步

以后续任务卡和 GG-239 当前检查点为准；本卡保留当时范围与证据。

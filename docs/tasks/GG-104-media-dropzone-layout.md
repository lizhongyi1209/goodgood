# GG-104 — 创作器拖拽上传、错误反馈与视频素材入库

- 状态：本地代码与门禁验证完成，待本地迁移与运行预览；未部署。
- 基线：GG-103 `1f24318`；分支 `codex/GG-104-media-dropzone-layout`。
- 需求：图片和视频可拖入创作器，先显示本地预览、后台上传；上传前给出明确的大小限制，失败保留关键原因；素材托盘放在输入框上方，图片/视频切换放在下方。
- 决策：[ADR 0095](../decisions/0095-composer-drop-and-private-video-materials.md)。用户确认视频上传成功后进入私有素材库，供下次复用。

## 验收

1. 拖入支持的图片或视频立即出现本地预览和上传状态；图片模式拖入视频自动切到视频模式。拖拽排序仍可用，拖入不提交生成。
2. 图片在浏览器端按现有私有原图上限 20 MiB 检查；不合格文件不加入托盘，提示文件名、允许大小/格式。视频按 200 MiB 检查。
3. 上传失败在托盘显示可读原因并可重试；独立文件互不阻塞。
4. 视频使用所有者隔离的私有对象存储，上传成功后在资产库和视频素材选择器可复用；持久视频上传不启用带素材的视频生成。
5. 定向测试与 `npm run check:local` 通过；本地预览来源与运行健康核实。不调用付费生成，不修改生产数据或部署。

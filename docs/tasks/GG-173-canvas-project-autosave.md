# GG-173 · 画布项目实时保存与离线恢复

## Scope and acceptance

每个新画布取得稳定项目 ID 与 `/canvas/:id` 地址，并出现在「项目」列表。画布名称、节点位置与四角尺寸、连线、生成器提示词/模型/规格/直接参考图、视口和已确认的生成结果持续保存；刷新、关闭后从同一地址恢复。电脑拖入或直接选取后尚在上传的本地文件由 IndexedDB 暂存，失败/断网时保留并可重试。服务器保存失败与浏览器存储失败分别说明，绝不把未确认写入显示为「已保存」。多标签版本冲突保留当前内容为新画布项目并提示，不覆盖远端原项目。创建或恢复不自动触发生成与计费。

GG-175 后续决定将日常视角变化改为本机偏好，平移/缩放本身不再触发项目同步；见 [GG-175](GG-175-canvas-content-scoped-autosave.md)。本任务记录原始持久化范围。

## Implementation

- 新的 owner/workspace-scoped `canvas_projects` 表和 `/api/canvas-projects` GET/GET:id/PUT:id，使用客户端 UUID、expectedVersion/CAS 与同内容重试幂等；与旧的至少包含一个生成批次的创作项目分开。
- 版本化纯数据图快照；保存前排除 Blob、签名地址、回调、选中态和仅本地的待上传对象。授权读取素材与任务后重建节点。
- IndexedDB 按稳定用户 ID 保存文档和待上传 File，前端先落本地再串行同步服务器；React Flow store 订阅捕获内部尺寸与视口变化，操作稳定后合并写入；网络恢复和手动点击可重试。
- 项目页合并画布项目和旧创作项目；仅本地未同步的画布仍可从同一浏览器项目页打开。旧创作项目路由和生成项目合同保持。

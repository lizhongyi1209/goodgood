## 范围与验收

- `/canvas` 上已加载的本地图片与生成图片，鼠标悬停时显示紧贴直角图片的一像素亮蓝色轮廓，与选中轮廓一致；图片内容不再变暗。
- 悬停不改变节点选中状态，不额外显示缩放控件或操作按钮。选中后的四角等比缩放、自由拖动和生成图片详情入口继续可用。
- 加载/失败状态、资产页卡片和输入区缩略图不在本次范围。

## 实施与验证

`canvas-workspace.module.css` 让 `.imageNode:hover` 与 React Flow 的 `.selected` 使用同一条一像素蓝色轮廓规则，并移除原悬停伪元素遮罩与过渡。图片节点结构、点击、拖动及缩放逻辑未修改。站长明确要求改完后不复测，由站长自行在页面手动检查；本次未运行测试或浏览器检查，未替换 32131 检查点或部署生产。

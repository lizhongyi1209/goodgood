# GG-181 · 画布 chat 圆角背后的直角阴影

- 状态：GG-116 本地样式已修改，待站长手动验收；未提交、未部署。
- 请求：站长 2026-09-29 指出图片生成器下方 chat 虽有圆角，背后仍能看到淡淡的直角。
- 决策：缺陷修正，保持 [ADR 0108](../decisions/0108-standalone-canvas-image-generation.md) 已确认的白色圆角输入区；不改变产品方向，无需新 ADR。

## 定位与范围

React Flow `NodeToolbar` 是 chat 的外层滚动容器。它原本无圆角且裁切内容，内部 `.composer` 的阴影超出卡片时会被矩形滚动边界截断，形成浅色直角轮廓。

外层工具栏现在使用与输入卡片一致的桌面 22px / 窄屏 17px 圆角，接管原有浅阴影；附着状态的内部卡片取消重复阴影。保留输入区边框、背景、最大高度、滚动、位置和交互。

## 验证与恢复

仅做静态差异检查。按站长持续要求，未运行自动测试、构建或浏览器复测；由站长在 5173 `/canvas` 手验 chat 四角和长提示词滚动。后端及持久化不变。

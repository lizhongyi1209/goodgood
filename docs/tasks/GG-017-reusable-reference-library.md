# GG-017 — 可复用参考素材库

- 状态：已上线；生产所有者边界验证通过
- 用户需求：上传过的参考图进入资产库，并可在后续创作中直接选择复用，不必重复上传
- 最后更新：2026-09-09
- 分支：`feature/GG-017-reusable-reference-library`
- 依赖基线：本地组合候选 `6ba59cd`，包含 GG-004—GG-016；最终随 `65ceb168` 上线
- 决策：[ADR 0037](../decisions/0037-reusable-uploaded-reference-materials.md)

## 范围与验收

- 资产库新增“上传素材”板块，列出当前用户已校验通过的参考图，按上传时间倒序。
- 创作器可选择“上传本地图片”或“从资产库选择”；已有素材按稳定 ID 加入参考图托盘，
  不再次上传对象字节。
- 同一个素材不会在同一托盘中重复加入，新增选择遵守最多 10 张和稳定选择顺序。
- 新上传完成后无需刷新页面即可进入可复用素材数据源。
- 列表、签名读取和复用保持所有者隔离；加载、空状态和失败状态均有明确恢复入口。
- accepted/ready 素材不再因暂时未被草稿、项目或生成任务引用而被 30 天清理；历史已
  标记但尚未删除的 `REFERENCE_ORPHANED` 素材会被救回。
- 不做素材删除、重命名、标签、文件夹、内容哈希去重或生产发布。
- 自动化测试不得连接 3010 的真实 provider Worker，也不触发付费生成。

## 范围与验收

- GPT IMAGE 2 允许 `1 / 2 / 4`；一次点击仍是一个批次和一个上游任务，提交的 `n` 等于冻结的数量。
- 每张 10 积分，因此 1 / 2 / 4 张的批次价格为 10 / 20 / 40；预留、成功结算和失败释放仍按整批原子处理。
- Worker 校验上游返回数量，下载并解码每张图片，按 ordinal 存入私有对象存储，并在一个事务中写入全部 Asset。
- 任务与资产 API 返回同批全部图片且顺序稳定；创作流、项目和资产库均能显示。
- 首版整批成功或整批失败，不公开部分结果。失败时清理本次已写对象并保留现有恢复入口。
- Nano Banana 2 当前上游契约没有数量参数，继续只支持 1 张；切换模型时将不兼容数量归一为 1。
- 不包含生产发布、真实付费上游冒烟、Nano 多输出或部分结果结算。

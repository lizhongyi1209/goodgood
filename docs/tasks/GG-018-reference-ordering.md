## 范围与验收

- 参考图托盘内每项左下角持续显示 `图 1…图 10`，增删和排序后连续重编号。
- 支持将参考图拖到另一张参考图的位置，并提供拖动项、落点的可见反馈。
- 支持聚焦后使用 `Alt + ← / →` 排序，保留移除按钮和上传/失败状态语义。
- 排序直接更新现有参考图数组；根草稿自动保存、显式项目保存和生成快照继续按该数组
  顺序持久化/提交。
- 不改变资产库素材排序，不新增数据库字段、第三方拖拽依赖或生产发布。
- 自动化和浏览器验证不得点击生成，不触发真实 provider 请求。

# GG-162 — 画布资产列表缩略图密度

- 状态：本地界面已修改，待站长在 `/canvas` 手动验收；GG-116 工作区未提交、未部署。
- 请求：画布左侧资产列表中的素材缩略图再缩小，减少每行视觉杂乱；图片与视频在方形小图中始终以原图中心裁剪展示。
- 决策：这是 GG-155 已确认列表样式的尺寸微调，不改变资产浏览、拖入、改名、预览或上传方向；无需新增 ADR。

## 范围与实现

- 素材小图由 34×34px 改为 28×28px，占位类型图标同步缩小。文件夹图标仍为 34×34px，列表行仍约 49px 高。
- 小图触发区宽 28px，两侧各留 3px，使文件夹和素材文件名保持同一列；悬停或键盘聚焦仍在小图位置打开较大的完整预览。
- 图片与视频小图使用 `object-fit: cover; object-position: 50% 50%`，在正方形中裁剪原画面中心；较大预览继续 `contain`，不裁切。生成图与上传图的私有 `/preview` 处理仅按比例缩入 512×512 的上限，未先行中心裁剪；视频使用原素材 URL，前端同样居中裁剪小图。
- 不修改资产页、服务端预览、真实上传、文件夹行高、文件名省略、右侧箭头、拖入画布和双击改名。

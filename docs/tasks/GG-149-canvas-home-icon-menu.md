- 右上角积分余额、纯白画布、地图与底部生成工具不改；菜单不触发上传或生成。
- 站长再次反馈内部 G 图形过于普通：保持 26px 黑底圆形外观和菜单行为，仅将白色字形改为更有识别度的折返斜笔画。

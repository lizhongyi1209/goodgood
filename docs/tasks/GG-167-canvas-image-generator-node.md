# GG-167 — 画布图片生成器节点与参考图连线

- 状态：GG-116 未提交工作区包含前端和配套后端；本 `feature/GG-167-runtime` 分支从已验证的 `b12f699` 单独提取后端接口，供本地 32131 构建和运行。尚未手验生成资产转参考图；未运行功能测试或浏览器复测，未部署。
- 请求：右键「图片生成」创建浅灰图片占位节点。原固定底部输入区默认隐藏；仅选中生成器节点时在其下方出现原输入区。画布图片可连线进入生成器，作为该生成器的真实参考图。
- 决策：[ADR 0108 补充](../decisions/0108-standalone-canvas-image-generation.md) 取代原先底部固定输入区及 GG-163 禁用右键入口。

## 验收范围

- 在空白画布右键创建临时生成器，节点可移动和选择。新建不触发上传或生成；重复创建不会覆盖其他节点。点击一个生成器显示输入区，点空白或其他素材隐藏，删除选中生成器时同步隐藏。
- 输入区复用参考图上传、提示词、规格、模型、报价和显式生成。节点下方保持可读大小，视口/窄屏下尽量保持可见；原页面底部固定输入区撤下。
- 图片到生成器使用 React Flow 原生连接点与边。只允许来源有可用服务端引用的图片；上传中或失败的来源不得作为可提交的引用。连线对应的参考图随选中生成器展示，断线即移除，累计上限十张；视频、音频和无可用私有引用的图片不应形成虚假可生成连线。
- 多个生成器的提示词、模型/规格、直接上传参考图和图片连线各自归属。已有图片节点的移动、缩放、预览、原上传与结果展示行为保留。画布节点、连线和位置仍不持久化。

## 验证与后续

`features/canvas/canvas-generator-node.tsx` 使用 React Flow NodeToolbar，现有输入区通过同页面 portal 装入选中节点下方；受控 edges 和逐生成器草稿位于 GG-116 的 `canvas-page.tsx`。本地上传图片直接取得 ready reference ID；生成结果与资产库生成图片经 owner-scoped `POST /api/references/from-asset` 转存为常规 ready 参考图，JPEG/PNG 保留原格式，WebP 在服务端转成支持的格式。同一生成图片正常重复导入复用引用，被用户删除的引用不复活。本运行分支只包含新后端接口，页面仍从 GG-116 热更新；切换本地 32131 前不能宣称生成图连线可用。

按站长持续要求，不运行自动测试或浏览器复测；仅为本地手验准备经过来源验证的后端构建，不自动提交真实生成或上传。站长在兼容运行版本就绪后手验空画布创建、选中/取消、节点拖动与缩放视口、窄屏位置、连接/断开、上传状态和多节点切换。

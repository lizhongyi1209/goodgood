> 后续 [GG-183](GG-183-canvas-video-preview-fit.md) 修正视频节点比例并取消 FPS 展示与解析；本卡保留当时的历史范围。

- 状态：本地代码已修改，待站长手动验收；沿用 `F:/goodgood-worktrees/GG-116` 当前分支及未提交画布改动，不切分支、不部署。
- 请求：将本地视频拖入画布，按图片节点的移动、缩放和顶部信息方式展示；左侧以播放三角形作为视频类型图标并显示文件名，右侧显示原始像素尺寸和 FPS。静止时封面中央显示播放图标、左下角显示时长；悬停时播放并隐藏两项，离开时暂停、恢复两项，下次悬停从暂停位置继续。
- 决策：本地 MP4 临时节点，不上传、不生成、不保存；扩展 [ADR 0108](../decisions/0108-standalone-canvas-image-generation.md)。

## 范围与验收

- 拖放沿用画布位置、临时节点及 object URL 生命周期；图片拖放和 AI 输入区参考图选择不变。格式和大小遵守既有 MP4 / 20 MiB 合同。
- 视频按原比例初始展示，可随 React Flow 四角等比缩放；悬停/选中细边框沿用图片。顶部播放图标、文件名、右侧尺寸/FPS 沿用图片的单行布局；竖屏视频的默认宽度也应显示省略后的文件名。更窄时先收起 FPS，再收起名称与尺寸，始终保留播放类型图标。
- 视频宽高与时长来自视频原文件的媒体元数据；FPS 从文件元数据读取，不根据播放帧数猜测。缺失值显示横杠，调整节点尺寸或画布缩放不更改数值。
- 默认封面、中央播放符号、左下时长；悬停静音循环播放并隐藏覆盖信息，离开暂停且不清零进度，下次从暂停处继续。页面失焦或减少动态效果时不继续自动播放。
- 不支持的、空文件、超限或无法解码的视频给出可恢复错误，不上传或占用持久资源。节点移除和页面退出释放对象 URL。

## 验证与后续

已添加 MP4 混合拖放、临时视频节点和复用的媒体信息组件。FPS 使用浏览器端按需加载的 MediaInfo WASM 串行读取，视频文件不传服务器；MP4 播放由 HTMLVideoElement 负责，离开悬停只暂停、不清零。站长要求后续改动不复测；本项未运行自动测试或浏览器检查，由站长在 5173 `/canvas` 手动验收，尤其检查本地浏览器对 WASM 静态资源的加载、FPS、封面及续播。未触发真实上传/生成，未替换 32131 或部署生产。

站长随后指出竖屏视频节点未展示文件名，已把名称收起阈值改为与图片一致、将 FPS 作为更窄时优先收起的字段，并把顶部视频类型标记改为播放三角形。此调整仍待手动验收，未复测。

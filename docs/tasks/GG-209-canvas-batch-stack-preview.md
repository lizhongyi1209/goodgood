## 范围与验收

1. 成功多图批次收紧时完整展示首图，最多仅露出两层自然平放的后图边缘。层叠总宽不随 4/8 张继续增长；不旋转、不悬停换图。
2. 展开/收起按钮固定在首图右下角，不随最右输出移动。保留可访问名称、键盘操作与展开状态，不触发节点拖动。
3. 点击按钮仍将全部输出按原顺序在同一 React Flow 节点向右展开，再次点击收紧；隐藏的后图不被丢弃，不拆散批次。
4. 单行生成器元数据与首图真实尺寸、提示词参数、输入连线、资产、任务、计费、项目快照不变。展开仍为临时视图状态；减少动态效果时不作位移/淡出动画。

## 本地实现

- `canvas-generator-node.tsx` 将收紧深度限制到两层，单层向右 6–10px（节点宽的 3%）/向下 4px；多余输出仍挂在同一节点中，但收紧时透明、不命中鼠标且对读屏隐藏。展开后所有输出依原顺序向右排开，12px 间隔不变。

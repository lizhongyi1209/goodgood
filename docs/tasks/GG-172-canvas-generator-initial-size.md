# GG-172 — 画布图片生成器初始尺寸

- 状态：GG-116 未提交工作区已修改，待站长手动验收；未部署。
- 请求：新建图片生成器的视觉尺寸尽量接近初始图片节点，原 124×124px 方块显得过小。
- 决策关系：[ADR 0108 补充](../decisions/0108-standalone-canvas-image-generation.md) 调整生成器初始占位尺寸；现有生成和连线语义保持。

## 验收范围

- 桌面新建的方形生成器与方形图片使用相同的 238px 初始上限；窄屏复用 `initialCanvasImageSize` 的视口比例限制，保持方形与画布可见空间。
- 右键创建位置仍对应节点中心，不因放大后偏离指针。下方输入区依据节点实际宽度定位和避让视口边缘，不继续用 124px 硬编码。
- 生成器仍只有浅灰占位、细线图像符号和原有悬停/选中状态。参考图连接、输入区和生成请求不变。

## 验证与后续

代码改动限于 `canvas-page.tsx` 的初始尺寸与中心定位、`canvas-generator-node.tsx` 的实际宽度定位和符号大小。仅运行 `git -c core.safecrlf=false diff --check`；按站长持续要求，不运行自动测试、构建、浏览器复测或真实上传/生成。站长在现有 5173 `/canvas` 手验桌面/窄屏新建、选中后输入区位置及与图片节点的尺寸关系。

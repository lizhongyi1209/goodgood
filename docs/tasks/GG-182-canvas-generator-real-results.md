# GG-182 · 图片生成器展示真实生成结果

- 状态：GG-116 本地代码已修改，待站长手动验收；未提交、未部署。
- 请求：2026-09-29 站长要求以 Nano Banana 2 为例，点击生成后在原生成器内显示真实任务动效和图片，保留参考图连线；多个生成器编号，完成后点图片仍打开保存了提示词和参数的 chat。
- 决策：[ADR 0108 的 GG-182 修订](../decisions/0108-standalone-canvas-image-generation.md#gg-182-amendment--results-belong-to-their-generator-2026-09-29)取代新任务另起首张结果节点的行为；项目持久化沿用 ADR 0114。

## 本次范围与实现

- 复用现有认证、报价、参考图和 `/api/generations` 提交/轮询接口。只有用户点击生成才发出真实且可能计费的请求；开发中不实际提交。
- 发起节点独立保存任务状态。队列及生成中使用上传图片同款轻暗遮罩与呼吸玻璃光；完成后在该节点展示首张图片，失败时保留节点与错误提示。其他生成器可独立提交。
- 生成器按建立顺序显示稳定序号；复制粘贴得到新序号。直接参考图和 React Flow 连线不因任务状态变化而重建。若数量为 2/4，其余真实输出继续成为现有结果节点。
- 每个生成器继续保存自己的提示词、模型、比例、分辨率、数量；提交时锁定其有效值。项目记录生成器序号和已确认的 job ID，刷新后读取授权任务；未完成的既有任务只继续轮询，不自动重新提交。旧的独立结果节点仍可恢复。
- 同一生成器的任务在排队或生成中时，提示词、模型和参数暂不可编辑，完成后恢复；其余生成器仍可独立编辑和提交，避免当前结果对应的提示词被后台输入覆盖。
- 服务端项目校验允许生成器关联 job ID/序号。服务端不保存本机临时任务 ID、回调、签名链接或文件；本机结果预览回退到受权限保护的资产预览路径。未收到服务端任务 ID 而刷新时明确提示状态未确认，不自动重复付费提交。

## 验证与待办

当前 5173 热更新仍把一般 `/api` 代理到已验证的旧 32131。旧服务端不识别新生成器 `jobId/sequence`，所以本地另起受限开发 sidecar：32132 运行当前源码的 Node API，Vite 只将 `/api/canvas-projects` 转到它，其余 API 仍走 32131。sidecar 仅监听 127.0.0.1，使用同一隔离数据库与登录 cookie，不启 Worker，也不声称是已验证检查点。32132 停止时画布项目保存会按现有机制提示未同步，本机草稿仍在；重启 `node --env-file=.env.login-review scripts/local-canvas-project-sidecar.mjs` 即可恢复。生产没有此代理分流；正式发布需统一前后端版本。

仅做静态差异及进程/健康检查：32132 返回 `development-gg182-unverified` / `build=null`，5173 的其他 API 仍见 32131 已验证版本。按站长持续要求，未运行自动测试、构建、浏览器复测或真实生图请求。请站长在 `/canvas` 手验 Nano Banana 2 单图、多生成器、参考图连线、刷新恢复、失败状态及 2/4 张输出。实际端到端生图、计费和线上部署均未验证；生产未变。

32142 Worker 在本任务收尾时仍关闭。只读审查发现隔离开发数据库有一条较早的 `nano-banana-2` queued 任务，已预留个人积分，且在全局 Valkey ready 队列中。现有 API 没有安全取消接口，Worker 也没有只消费新任务的过滤；直接启动会处理旧任务。旧任务的安全取消及 Worker 启动由站长另行授权的 GG-184 负责，本任务没有修改旧任务、队列或账本。

## 范围与验收

- 左下角入口与现有地图、缩放控件同列，仅显示资料库图标。侧栏从页面最左侧覆盖画布，不改变 React Flow 容器尺寸；地图、缩放入口、标题及输入区随侧栏右缘让位；入口、关闭按钮或 Esc 可收起。画布内容与节点状态保持原状。
- 根层展示文件夹和素材；进入文件夹显示归属其下的素材，可返回根层。缩略图与文件名同列，名称过长省略。
- 图片悬停或键盘聚焦时显示比缩略图大的完整比例预览；视频显示较大的动态预览，音频只显示对应图标和名称，不伪造图片。
- 加载、空列表、读取失败与重试有明确状态；演示会话不请求私有资产。读取不修改资产、文件夹、画布节点或计费状态。

## 验证与后续

已在现有 React Flow 左下角控件前加入纯资料库图标入口；点击后从最左侧展开白底侧栏，覆盖画布左边而不缩小 React Flow 容器。标题、输入区、左下角地图及缩放入口按侧栏宽度向右让位；新生成节点以未遮挡区域为中心放置。侧栏默认最大宽度 248px；右缘鼠标悬停仅显示横向缩放光标，不显示深色描边，可拖动扩至最多 400px，同时保留至少 280px 可见画布宽度，桌面端支持左右箭头微调。站长报告持续拖动时出现 vinext `ResizeObserver loop completed with undelivered notifications`；第一版延迟到松手生效被站长否定，现改为按动画帧合并指针更新，让侧栏与浮在画布上的控件实时同步移动，同时避免每条指针事件都触发 React 重渲染。React Flow 容器的尺寸在拖动时保持不变。取消拖动恢复原宽。宽度仅在当前页面状态中保留，刷新重置；560px 及以下隐藏拖动命中区。文件夹名和素材名超过剩余行宽时单行省略。侧栏以 shadcn ScrollArea 滚动，复用个人资产、上传素材和文件夹读取接口，文件夹可进入与返回。图片和视频有 40px 缩略图及较大的 Tooltip 预览；音频使用类型图标，所有素材同列展示文件名。列表包含读取中、空、失败与重试状态，入口、Esc 或关闭按钮可收起。当前只读，不创建画布节点。

## 侧栏行宽与名称省略补充（2026-09-28）
站长截图指出文件夹箭头被右侧裁切、长文件名没有省略。侧栏的外宽原本随拖动变化，行也声明了百分比宽与文字省略；实际是 shadcn ScrollArea 所用 Radix Viewport 的内容层使用内联 display: table，长名称可把其内在宽度撑过侧栏。因此仅在画布资产面板内把该内容层改为占满视口宽度的 block，行宽随侧栏变化，右侧保留 16px 内边距避开滚动条和拉伸边缘。保留现有文件夹进入、素材预览和键盘焦点行为。未运行测试、构建或浏览器复测，由站长手动验收窄栏、拉宽、长文件夹名和长素材名。

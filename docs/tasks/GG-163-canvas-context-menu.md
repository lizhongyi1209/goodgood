# GG-163 — 画布右键菜单入口

- 状态：本地界面已修改，待站长手动验收；GG-116 未提交、未部署。
- 后续：GG-167 已明确首项的功能，禁用占位状态由创建临时图片生成器节点替代；右键范围与浏览器菜单拦截规则沿用。
- 请求：`/canvas` 不再显示浏览器原生右键菜单；画布空白处右键在指针附近打开画布菜单，首项为「图片生成」，具体功能后续再定。
- 决策：这是独立画布的局部交互扩展，不改变 ADR 0108 的白色简洁画布或生成提交边界，无需新 ADR。

## 范围与实现

- 复用已有 shadcn/Radix `ContextMenu`。只有 React Flow 空白 pane 能触发菜单；图片、视频、音频节点、地图、缩放控件、资产栏、顶部与输入区右键不会误弹空白画布菜单。
- 画布页面挂载期间拦截其余位置的原生浏览器菜单；离开画布页面后移除监听，不影响大厅等路由。菜单保留 Radix 自带的指针定位、视口避让、Esc 与点击外部关闭行为。
- 「图片生成」暂为禁用占位项，点击不提交任务、不修改提示词或节点；功能内容等待后续产品需求。菜单使用页面已有白底黑字、浅灰边框样式。

## 验证与后续

- 已静态检查 React Flow pane 的右键事件与 Radix ContextMenu 的默认阻止和定位逻辑；按站长持续要求，不运行测试、构建或浏览器复测。
- 站长手验：空白画布右键出现贴近指针的菜单；节点、资产栏、输入区和顶部右键不出现浏览器菜单；Esc、点击外部关闭，离开 `/canvas` 后其他页面右键恢复原行为。

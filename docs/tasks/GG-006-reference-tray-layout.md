# GG-006 — 放大参考图预览并调整参数顺序

- 状态：待验收（本地已实现并完成浏览器验证，未发布）
- 用户需求：上传参考图后适当放大 1:1 居中预览，并将画面比例从中间移到左侧。
- 最后更新：2026-09-07
- 开发分支：`feat/GG-006-reference-tray-layout`
- 基线：`bab17fd4d4c4d88eec6194bb5d024769ca8e26fa`
- 决策：[ADR 0029](../decisions/0029-enlarge-square-reference-previews-and-lead-with-aspect-ratio.md)；
  取代浏览器初审后被否定的矩形方案 ADR 0028。

## 范围与验收

- 桌面参考图预览从 46 px 方形放大为 `64 × 64 px`，移动端为
  `56 × 56 px`；添加控件沿用同一尺寸，图片保持 1:1 居中裁切。
- 参考图托盘继续横向滚动、不换行，保留最多 10 张、上传/失败状态、移除操作与
  无障碍序号语义。
- 参数抽屉按“画面比例—生成模型—输出”排列：宽屏比例在左；中等宽度比例在首行；
  移动端按相同阅读顺序纵向排列。
- 更新设计与交互文档，增加布局契约测试；执行 `npm run check:local`。
- 将 GG-006 合入本地真实 O1Key 联调候选并完成浏览器视觉核验，供站长实测。
- 非目标：不改生成参数数据结构、参考图上传协议、图片详情页或线上环境。

## 实现与证据

- 实现：参考图与添加控件使用共享响应式尺寸；图片明确采用 `cover` 和中心定位；
  删除按钮收进缩略图右上角，避免被横向滚动容器裁切。
- 实现：参数组 DOM 与视觉顺序改为“画面比例—生成模型—输出”；1180 px 及以下比例
  先占首行，720 px 及以下按同一阅读顺序堆叠。
- 决策迭代：首次矩形方案完成浏览器初审后被站长否定，ADR 0028 如实保留为
  Superseded；最终 1:1 方案记录在 ADR 0029。
- 验证：方形契约测试在矩形实现上先失败；实现后专项测试和类型检查通过。
  `npm run check:local` 共 193 项，189 通过、4 个 opt-in 跳过、0 失败。
- 联调：组合分支 `test/GG-004-GG-005-local` 的本地镜像保留原数据卷重建成功；
  `stack:verify` 确认 Web、Worker、provider、PostgreSQL、Valkey、对象存储全部 ready。
- 浏览器：1755 px 桌面视口实测参考图 `64 × 64`、中心定位 `50% 50%`，画面比例位于
  最左列；390 px 移动视口实测 `56 × 56`，参数组按比例、模型、输出纵向排列。
- 生产状态：未部署；本任务授权范围为本地实现和联调验收。

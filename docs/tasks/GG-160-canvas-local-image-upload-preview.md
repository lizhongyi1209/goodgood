后续变更：GG-161 已将电脑拖入的本地 JPEG/PNG/MP4 接入真实上传；本任务的固定三秒计时、假成功和「不入库」结论仅保留为历史记录。视觉上的原位呼吸光继续用于真实上传期间，直到请求完成。见 [GG-161](GG-161-canvas-local-media-upload.md)。

- 状态：本地界面已修改，待站长手动验收；未提交、未部署。
- 日期 / 工作区：2026-09-28；`F:/goodgood-worktrees/GG-116`，`feature/GG-116-asset-history-actions`。
- 来源：站长参考截图，希望画布图片放入时显示约 3 秒的模拟上传过程，不显示「上传中」，结束后正常展示并选中。淡白渐隐不够明显；窄玻璃扫光虽好看但画面显空，现改为原位呼吸光效。
- 决策：沿用现有本地拖入临时节点边界；这是纯前端预览动画，不执行真实上传，不改变已上传资产与生成结果的读取路径，也不改变已确认的产品方向。

## 范围与验收

- 本地 JPEG/PNG 拖入画布后，图片保持清晰，上方有轻暗遮罩与覆盖大部分画面的柔和玻璃光晕；光晕原位明暗呼吸两次，不横扫；约 3 秒后移除。不加上传文字、圆环、进度弹框或服务端请求。
- 3 秒结束后图片按原有比例、元数据和交互正常显示，新增图片节点进入选中状态；同一次放入多张图片时这些图片同时选中。
- 拖入现有资产、生成结果、本地视频和音频不模拟上传。删除未完成的节点不会重新出现；离开页面清除定时器和原有 Blob 地址。
- 现有移动、四角缩放、删除和参考图真实上传流程保持。

## 实现与证据

- `canvas-page.tsx` 只给本地图片节点附加临时 `previewPending`，创建节点后启动一次 3 秒计时，结束时通过 React Flow 自身的非受控节点状态清除标记并选中本批图片；页面卸载清除计时器。
- `canvas-source-node.tsx` 依据临时标记设置样式及 `aria-busy`；`canvas-workspace.module.css` 使用不拦截指针的轻暗遮罩和全幅径向光晕，只动画透明度与轻微缩放，结束时才呈现选中细框。减少动态效果偏好下只保持静态遮罩直到计时结束。
- 站长确认呼吸光方向「好多了」，要求视觉稍明显：保留原位节奏与范围，仅略加深底层遮罩、提高光晕和内沿亮度，并拉开呼吸明暗差；不增加扫光或新控件。
- 不涉及后端、数据库、计费、真实上传或发布。按站长要求不运行测试、构建或浏览器复测；仅做静态 diff 检查。下一步由站长在 `/canvas` 手动拖入一张/多张本地图，观察 3 秒外观、完成选中、缩放与删除。

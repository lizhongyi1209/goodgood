## 决策与范围

本任务实现 ADR 0144 已接受的中性设计系统，不新增或改变产品决策，因此不新增 ADR。按用户指定的顺序分四笔提交：文档与任务卡、共用外壳、图片页、视频页。

- 从 GG-423 首页抽取共用工作区外壳：完整侧栏、768–1199 图标栏、手机顶栏和底部标签栏、账户菜单。首页、图片页、视频页共用；项目、资产、画布和管理页继续使用旧外壳，后续逐页迁移，避免本任务扩大视觉和回归范围。
- 图片页使用固定 `panel-width` 的 SettingsPanel，字段顺序为模型、参考图、提示词、比例与分辨率、数量、GPT Image 质量；生成记录使用 RunGroup + MediaTile，点开 MediaViewer。复用现有上传、生成、轮询、资产入库、积分和重试边界，不改后端或计价，价格只在 GenerateButton 内出现。
- 视频页复用同一面板外壳和现有 Seedance 提交/轮询/计价。字段顺序为模型、生成方式、素材、提示词、比例与分辨率、时长、生成音频；本轮只显示现有后端链路可提交的 `multimodal`（全能参考）和 `first_last_frame`（首尾帧）。设计稿中的视频编辑、视频延长等尚无本页提交合同，隐藏并延期，不伪造前端能力。
- 素材格式与实际持久素材 / Seedance 链路统一为 JPEG/PNG 图片、MP4/MOV 视频、MP3/WAV 音频；浏览器同时按扩展名和 MIME 识别 `video/quicktime`、`audio/wav`、`audio/x-wav`。既有服务器已按这些格式校验和读取元数据，本轮只补齐创作页选择器和前端校验，不改服务端。
- 异常只接已有信号：上传失败虚线框 + InlineNotice、积分不足提示条、点生成后显示缺少提示词/素材等必填项、任务审核/失败信息原位显示并保留既有重试、浏览器离线 Toast。没有独立错误码或恢复接口的更细分审核行动（例如精确区分提示词与某个素材并自动定位）保留为后续服务合同工作。
- 桌面两栏各自滚动；≥1200 使用完整侧栏，768–1199 使用图标栏。手机本轮采用面板在上、生成记录在下的单列过渡方案；后续可在真实设备验证后决定是否改为抽屉或分段视图。
- `VITE_GG_HOME_DEMO` 仍只控制批量和对话等未接后端入口；本任务不实现批量或对话。

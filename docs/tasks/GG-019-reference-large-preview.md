## 范围与验收

- 点击 ready 参考图打开聚焦的大图预览，完整显示原图且不裁切，适合检查纹理等细节。
- 大图预览显示当前 `图 N` 与文件名，可用关闭按钮或 Escape 退出。
- 上传中和失败项不打开预览；拖拽排序结束不误触预览。
- 聚焦 ready 项后可用 Enter/Space 打开；原有 `Alt + ← / →` 排序保持不变。
- 删除按钮缩小并贴近缩略图右上角；删除事件不冒泡到大图预览。
- 不改变参考图持久化、生成快照、素材库、provider 或生产发布。
- 自动化和浏览器验证不得点击生成，不触发真实 provider 请求。

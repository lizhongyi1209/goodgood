# GG-200 · 画布连线悬停亮蓝反馈

## 请求

已连接的画布线条在鼠标悬停时以很亮、清晰的蓝色点亮；离开后恢复当前中性灰。现有曲线、流动虚线、一秒后出现的剪刀按钮、删除行为、拖拽预览和减少动态效果均保留。

## 决策

这是对无彩色画布视觉规则的定向修订。仅已连接边在悬停期间使用 `#1687ff`；默认线条和拖拽预览继续使用既有中性灰。实现复用 React Flow 边容器的原生 `:hover` 状态，只改变可见 `.react-flow__edge-path` 的 `stroke`，不修改透明交互路径及其命中宽度，也不为指针移动新增 React 状态或重渲染。

颜色变化使用 120ms 过渡；系统启用减少动态效果时立即切换。流动虚线动画、曲线参数、剪刀按钮的延时与定位、删除数据路径均不变。

## 验收

- 指针进入任意已连接边的现有宽命中区时，可见线条变为 `#1687ff`。
- 指针离开后线条恢复中性灰，不保留蓝色状态。
- 悬停不会缩窄命中范围，不影响一秒剪刀按钮、沿线跟随或删除。
- 虚线流动继续工作；减少动态效果时仍为静态实线且颜色无过渡。
- 拖拽中的预览线保持原有样式。

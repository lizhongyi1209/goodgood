## 范围与验收

- 要做：`/login`、`/register`；固定登录/注册子导航；注册页邀请码；受保护页面安全跳转登录；新用户验证后自动切注册；保留业务 `returnTo`。
- 不做：不新增认证方式，不预设账户，不发送真实邮件，不重置数据库，不调用真实生成 provider，不部署生产。
- 验收点：路由可直接刷新；登录不显示邀请码、注册显示；认证 URL 不含敏感字段；外部或循环 `returnTo` 被拒绝；验证码发送冷却不因改邮箱复原。
- 决策影响：改变 ADR 0087 的认证界面决定；由 ADR 0088 记录。

- 已实现：独立登录/注册页与固定子导航；注册页直接显示邀请码；受保护页跳登录；pending会话规范化到注册并预填邮箱；新用户服务端判定后保留挑战/邮件码切注册；成功后使用服务端安全业务目标。

# GG-141 — 画布 AI 输入区重构

- 状态：本地界面已修改，待站长手动验收；沿用 `F:/goodgood-worktrees/GG-116` 当前分支，未提交、未部署。
- 请求：参考站长提供的紧凑聊天输入框、模型菜单与图像设置弹层截图，重构 `/canvas` 底部 AI 输入区；优先复用 AI Elements 和 shadcn/ui。
- 决策关系：改变 GG-125 输入区的排布，保持纯白画布及真实生成边界；见 [ADR 0108 补充](../decisions/0108-standalone-canvas-image-generation.md)。

## 组件选择

- 复用项目已有的 shadcn `Textarea`、`Button`、`Select`、`Popover`、`ToggleGroup`，无须安装额外运行时包。模型菜单继续接现有报价目录。
- 核对 [AI Elements Prompt Input](https://elements.ai-sdk.dev/components/prompt-input)：它管理聊天提交与附件状态，当前画布使用独立私有参考图上传、批量报价、可恢复输入和 GoodGood 后端生成；直接替换会改变业务边界，本次不安装该组件或引入 AI SDK。

## 范围与验收

- 输入区保留白底灰阶，以紧凑的两层结构承载提示词和底部工具；已有参考图继续在提示词上方，不嵌进文本区。
- 底部提供参考图入口、当前比例与分辨率摘要、模型选择和生成按钮。图像设置向上展开，分辨率、模型支持的宽高比及生成数量都可选；当前选项和禁用状态清晰。
- 生成按钮在已有报价可用时显示积分数；提交、上传、失败重试、缺积分和报价不可用逻辑不变。键盘快捷提交与多行输入保持。
- 窄屏工具分为两行，弹层有高度上限，不遮断选择项。

## 实施与验证

只调整 `CanvasPage` 输入区的 shadcn 组合及局部 CSS。报价由原底部说明收进生成按钮；读取中或无法报价时保留文本提示。站长已要求后续改动不复测，待站长自行手动验收；本次未运行自动测试或浏览器检查，未触发真实上传/生成，未替换 32131 或部署生产。

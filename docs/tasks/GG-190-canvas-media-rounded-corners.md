# GG-190 · 画布图片与视频节点同步圆角

- 状态：GG-116 本地样式已修改，待站长在画布手验；未提交、未部署。
- 请求：生成器已有圆角，普通图片和视频节点也采用同样的圆角视觉。
- 决策：[ADR 0110 GG-190 补充](../decisions/0110-canvas-image-selection-frame.md#gg-190-addendum--shared-canvas-media-corners-2026-09-29) 取代 GG-136 的已加载图片直角决定。仅改画布媒体节点，不改资产库和参考图缩略图。

## 范围与验收

- 已加载的本地图片、额外生成结果图片及视频预览使用生成器同款 `min(8px, 4%)` 圆角；小节点缩小时圆角随之收敛。
- 图片和视频均由原节点容器裁切，悬停及选中时原有 1px 蓝色轮廓贴合圆角；四角透明缩放命中区和光标不变。
- 保持原图/视频比例、视频播放及上传态；加载失败和生成失败卡片维持既有样式。不引入额外比例包装或尺寸回写。

## 实现与验证

- `canvas-workspace.module.css` 用一个画布媒体圆角变量复用生成器的尺寸规则；源图、结果图和视频节点共享它。
- 按站长持续指示，未运行自动测试、构建或浏览器复测；仅做静态差异检查。下一步由站长在 `http://127.0.0.1:5173/canvas` 手验现有图片、结果图、视频的圆角和边框贴合。

# GG-020 — 参考图快捷编辑器

- 状态：已上线；移动端触控仍可继续人工复核
- 用户需求：大图左侧提供裁剪、画笔、贴图、箭头和 bbox 框选，并保持 GoodGood 视觉
- 最后更新：2026-09-09
- 分支：`feature/GG-020-reference-quick-editor`
- 依赖基线：本地组合候选 `863a73d`（GG-019）；最终随 `65ceb168` 上线
- 决策：[ADR 0040](../decisions/0040-reference-quick-editor.md)

## 范围与验收

- 大图左侧显示查看、裁剪、画笔、贴图、箭头、框选工具；选中与悬浮使用现有中性底色
  和 Palace Red，不偏离设计系统。
- 裁剪覆盖自由/原图与八种常用比例，支持移动和缩放裁剪区域。
- 画笔支持颜色、粗细、圈画与实色遮盖；箭头支持颜色和粗细。
- 贴图支持本地文件和现有素材，图层可移动、缩放、旋转和删除。
- 框选输出当前裁剪画布的像素及 0–1000 bbox，可复制或插入提示词，不写入导出图。
- 支持撤销、重做、重置；有未保存编辑时关闭需要确认。
- 完成后上传为新的持久素材，并在相同 `图 N` 位置替换当前参考图；原素材不变。
- 导出/上传失败保留编辑状态并可重试；不新增数据库、provider 或生产发布。
- 自动化和浏览器验证不得点击生成，不触发真实 provider 请求。

## 实现与证据

- `reference-editor-model.ts` 提供裁剪、历史、bbox 与贴图变换的纯模型；
  `reference-quick-editor.tsx` 提供高 DPI Canvas、工具轨、导出及失败保留。
- 新增所有者鉴权的 `GET /api/references/:referenceId/content`。浏览器不再跨端口读取
  私有对象，而是通过 GoodGood 同源边界读取已验证素材；路由日志隐藏具体素材 ID。
- 完成编辑先上传并校验新素材，再替换同一序号；在项目内还会同步 PATCH 项目快照，
  刷新后仍恢复新素材。原素材记录与对象保持不变。
- 定向测试 27/27 通过；最终 `npm run check:local` 共 245 项（239 通过、6 个 opt-in
  跳过、0 失败）。
- 3010 真实 Chrome 已验证：1696 × 2528 原图读取、1:1 裁剪与拖动、画笔、箭头、
  bbox `[186, 213, 429, 470]` 的复制/加入提示词、资产库贴图、贴图移动/缩放/旋转、
  撤销/重做、未保存关闭确认、真实导出上传及刷新恢复。
- 实测编辑结果为 1696 × 1696 PNG，非零大小 6,106,495 字节；第二次裁剪持久化复核
  为 6,090,856 字节。原 6,074,341 字节素材仍存在；项目测试后已恢复为原参考图。
  两张编辑结果保留为本地测试素材。验证前后活动 generation job/attempt 均为 0，
  未触发 O1Key 生图。
- 站长截图暴露取消二次确认框透明：通用 AlertDialog 的 `bg-background`、危险按钮等
  主题色在 GoodGood 当前 token 中没有有效值。已为该嵌套确认框增加独立轻遮罩、不透明
  白色卡片、明确标题/说明、宫墙红危险按钮和焦点样式；共享 primitive 新增可选遮罩类，
  不改变其他确认框。定向 lint/typecheck 与 UI 测试 16/16 通过。
- 3010 Chrome 已再次复现并复核：确认框完整遮住画布内容、按钮层级清晰；点击“继续编辑”
  返回后保留 1131 × 1131 裁剪状态。随后撤销测试裁剪并正常退出，未保存素材、未点击生成。

## 范围与验收

- 移动图片时保持跟手，不因页面上层状态的重复逐帧更新而重渲染输入区和资产栏。
- 现有节点的选中、缩放、删除，以及本地图片/视频节点删除时释放 Blob 预览地址继续可用。

## 排查与修改

- `CanvasWorkspace` 传给 React Flow 的是 `defaultNodes`。所装版本的 React Flow 在 `hasDefaultNodes` 时先自行应用节点变化，再通知 `onNodesChange`。原页面回调又用 `useNodesState` 对同一位置变化更新第二份节点状态，使整个 `CanvasPage` 随拖动逐帧重渲染；这是代码中可确认的性能负担，实际改善幅度待手验。
- React Flow 初始化后不再把节点变化逐帧同步到页面状态；初始化前仍保留原有状态路径。节点删除继续处理本地 Blob URL，改为按节点 ID 查表，避免 React Flow 删除后已无法用 `getNode` 取回节点。
- 按站长要求不运行测试、构建或浏览器复测；由站长刷新 `/canvas` 手动拖动多张图片，并检查删除本地图片/视频节点。仅做静态 diff 检查。

## 范围与验收

- 本地图片展示原始 `File.name`；生成图片展示资产页现有下载命名规则生成的文件名。图标、名称在图片上沿左侧，原始像素宽高（如 `1024×1536`）在右侧。
- 标签宽度跟随 React Flow 节点宽度且始终单行。长名称显示省略号，节点变宽且空间足够后自动完整显示；进一步缩窄时先隐藏文件名，再在极窄宽度隐藏尺寸，但始终保留左侧图片类型图标。
- 右侧尺寸读取本地原图解码像素或生成结果的后端原始尺寸元数据，从不读取节点当前 CSS 宽高或视口缩放值。本地解码未就绪时先显示横杠，图片载入后补齐；生成结果缺少原始尺寸元数据时保持横杠，不能把 512px 缩略图尺寸误作原图。
- 元数据不覆盖图片，也不增加悬停操作；本地与生成图片的选中、拖动、四角缩放和生成结果详情入口继续保留。加载/失败节点保持原状态。

# GG-171 — 画布连线流动效果与悬停删除

- 状态：GG-116 未提交工作区已修改，待站长手动验收；未部署。
- 请求：完成的图片参考图连线持续呈现轻微流动；鼠标停留在线条上 1 秒后，在鼠标附近出现小型删除图标，点击即断开该连线。
- 决策关系：更新 GG-170 的静态线条细节；曲率、灰色细线和参考图连接语义保留。见 [ADR 0108 补充](../decisions/0108-standalone-canvas-image-generation.md)。

## 验收范围

- 完成连线的动画低对比度、不中断原曲线和节点操作；偏好减少动态效果时为静态线。拖拽中的连接预览仍为原灰色细曲线。
- 只在同一条线悬停满 1 秒后显示剪刀删除按钮；按站长最新澄清，按钮的正中心始终压在贝塞尔线上，鼠标沿线移动时跟随最近的线段位置；提前移出不显示，按钮可点击，离开后收起。
- 点击按钮复用已有断线清理：目标生成器移除对应参考图，源图片和资产不删除。边本身仍支持 React Flow 原有键盘删除。
- 仅改 `/canvas` 的客户端组件和样式；不发起真实上传、生成或后端变更。

## 验证与后续

初版按钮固定在指针右上方；第二版在鼠标正下方。站长澄清目标是圆心压在线上，现改为按曲线路径几何位置放置并沿线跟随。`git -c core.safecrlf=false diff --check` 通过；按站长持续要求，未运行自动测试、构建或浏览器复测。站长在 5173 `/canvas` 手动验收不同线段位置、鼠标沿线移动、悬停计时、按钮点击、参考图托盘同步及减少动态效果。

- 状态：本地实现与门禁完成；待站长手动验收，未部署。

- 请求：`/canvas` 成为独立界面，不嵌入大厅；先加入常用图片生成能力，保持纯白、简洁。

## 验收

- 从大厅进入画布为完整页面导航；画布可回到创作，刷新和直接访问仍是独立页面。
- 提示词、参考图、模型、比例、分辨率、数量和明确的生成按钮可用；报价与可用模型来自现有计费接口，上传/生成复用现有服务边界。
- 空白、上传中、生成中、成功和失败状态清晰；成功结果作为可移动画布节点并能打开资产详情；失败可由用户明确重试。
- 保留纯白 React Flow 画布与灰阶缩放，不增加网格、示例、后端画布文档或自动付费请求。

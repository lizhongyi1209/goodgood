## 推荐方案

新增「批量生成」节点：节点自身有可收起的「参考组合」区，下方复用现有chat的提示词、模型、比例、分辨率、输出数量与发送。普通图片生成器保持。组配置不塞进提示词输入框或新增一整套聊天面板。

输入分为「公共参考」与可自定义名称的「素材组」：
- 公共参考的所有图片进入每个任务，例如固定模特、背景、风格图。
- 每个素材组提供候选项，每次选一项；默认单图。组名可改成主体、服装、配饰、商品、场景等，不硬编码换装业务。
- 框选/已有参考图组从共用端点连到批量节点某一输入行即可导入该组候选，保留组边界，不能扁平化成所有任务同时带入全部图。每行可排序、移除、追加；收起时显示组名/数量/组合总数。
- 同一素材的多视角/上衣与裤子需“多图一项”时，不能误算为不同候选；建议作为后续明确扩展，首版单图项边界清楚。

组合规则只有两种：
1. 全部组合：每组各选一项，覆盖所有搭配。公共模特1图+服装5项=5组；主体3项×服装5项=15组；再加配饰2项=30组。
2. 按顺序配对：各组第1项对应第1项。主体3项+服装3项=3组；单项组可复用，多项组数量不一致阻止生成并指明需调整哪组，不静默截断/循环。

共用一份提示词和设置；输入顺序为公共参考→素材组显示顺序，每个组合提供少量预览/展开全部以确认真实图序。提示词例如“保留图1的主体，换成图2的服装，佩戴图3的配饰”；若每个角色只有一张，序号稳定。多公共参考、去重及将来多图一项须按最终输入映射提示，不能假定组名会被模型作为角色参数理解。

生成前显示组合总数、预计出图数和权威报价。例如30组、每组2张，预计60张；不引入并发设置按钮，沿现有执行方式显式提交各组合。冻结当次组合/提示词/设置，之后画布改动不影响已提交任务。结果按组合顺序保留映射与状态，成功项可用，重试只针对选中失败项。

首版建议公共参考+素材组+全部组合/按序配对+数量预览+共用chat；暂不叠加随机搭配、条件表达式、每组独立提示词/模型/参数。既有分段提示词批量与参考组合的叠加语义要在实施前定义，建议此节点首版只使用一份共同提示词，普通节点原分段规则保持。

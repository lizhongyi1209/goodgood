# GG-175 · 画布内容变化才同步项目

- Status: GG-116 本地代码已修改，待站长手验；未部署
- Date: 2026-09-29
- Decision: [ADR 0114 amendment](../decisions/0114-durable-canvas-projects.md#gg-175-amendment--separate-content-from-the-view)

## Scope and acceptance

画布平移、缩放、适应屏幕、节点选中/悬停和预览播放不改变项目保存状态、不写服务端项目。当前视角可在同一浏览器刷新后恢复。新建空项目仍创建一次服务端记录。新增/删除/移动/缩放节点、连线、名称、生成器提示词/参数/参考图和结果身份变化继续保存；拖动与缩放结束后只提交最终几何状态，重复快照不写本地或服务端。离线时真实内容变更仍先写 IndexedDB，并保留 GG-173 的失败提示与冲突处理。

## Handoff

GG-116 将 React Flow 视角变化接入独立的本机偏好保存；图订阅避开拖动/缩放帧，项目同步按内容签名跳过相同快照，并在服务端内容未变化时跳过 PUT。沿用 GG-173 API、迁移与运行时，不需要后端切换。

仅做静态 `git -c core.safecrlf=false diff --check`；按站长持续要求不运行自动测试、构建或浏览器功能复测。手验平移、缩放、适应屏幕和选中节点不触发「保存中」；同浏览器刷新恢复视角；节点移动/缩放、连线和输入内容仍保存；空项目进入项目列表；断线后内容恢复。生产未部署。

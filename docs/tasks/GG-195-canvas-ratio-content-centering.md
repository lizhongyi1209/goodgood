# GG-195 — 画布宽高比选项图文垂直居中

- 日期：2026-09-29
- 工作区：`F:/goodgood-worktrees/GG-116`，延续 GG-194 竖向卡片。
- 决策：这是 GG-194 已确定布局的视觉对齐修正；模型、比例、交互和向下弹层不变，无需新 ADR。

## 范围与验收

1. 每张宽高比卡片的比例图形与文字仍上下排列，整体始终垂直居中。
2. 不同固定比例的图形高度和「自适应」图标高度不应使文字基线跳动。
3. 保留 76px 卡片高度、8px 图文间距、四列网格、窄屏排版、选中/悬停/键盘焦点和参数选择。

## 实施与状态

- 原 flex 布局虽然有 `justify-content: center`，但固定比例图形的实际高度在 7–20px 之间，「自适应」SVG 为 16px；整组按各自内容高度居中，导致图形与文字在不同卡片中的纵向位置不一致。
- `features/canvas/canvas-page.module.css` 的 `.ratioOption` 改为居中的两行 grid：图形槽 20px、文字槽 16px、间距 8px；图形和文字分别在槽中居中。未改 DOM、比例图形尺寸、参数或接口。
- 仅静态差异检查，未按站长要求运行自动测试、构建、浏览器复测或付费生成。待站长在 `/canvas` 手动查看自适应、横向和竖向比例的对齐效果；生产未变。

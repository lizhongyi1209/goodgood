## 范围与验收

- 仅单独一行 `---` 触发分段并发，图片和视频共用解析规则；空段忽略、重复段保留、全空阻止提交。
- 总输出=非空段数×数量；参数/素材共享冻结，各段状态/失败/重试隔离。
- 数量与图片积分预估准确；原输入保留，图片资产详情只显示对应单段。
- 原视频接口限制不变，不做真实 provider 请求或启用写 fixture。
- 验证解析、乘积、并发、乱序、失败、项目上下文与单段回归；完整本地门禁和现有 Chrome computer use。

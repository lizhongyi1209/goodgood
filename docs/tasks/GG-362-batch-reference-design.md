## 建议的首版交互

1. 框选至少2张图片后，多选外框右侧中点显示一个共用端点，悬停「连接5张参考图」；保留图片当前位置与尺寸，不要求先点击建组。拖线到图片生成器现有接收点即完成一次批量接入。
2. 只有有效落点/容量校验通过后才把临时选区保留为参考图组，已有纯图片组复用；取消拖线不建组或更改引用。组只有一条可见连接到目标，计数显示实际接入张数，点击/悬停可看对应图片。该持久来源解决取消选中后临时外框消失的问题，并可整组连接多个生成器。
3. 目标托盘仍逐张显示图片/编号，首次按画布阅读顺序（上到下、左到右）固定，移动图片不改参考顺序。一条线表示多张独立参考图，不合并成拼图；有加载图先显示占位，全部就绪前不能生成。
4. 断开整条线取消这组对当前生成器的引用，保留图片/组；托盘移除单张只排除它对当前目标的引用，不删图或影响其他目标。加入/移除组成员只影响后续生成；已提交任务固定当次引用快照。该目标独立排除与顺序需明确持久化，不通过隐藏副作用实现。
5. 仍最多10张，先对目标已有引用去重并预检整组容量，超额提示需减少的数量，不静默截断。首版限定可解析的图片来源，混合选区/含目标自身/循环/失效资产不能冒充有效图片组；失败保留现有引用。生成批次多输出的范围、解绑/重连后的排除恢复及跨页复制须在实施前定义，不能默认把一个生成器的全部历史输出加入。

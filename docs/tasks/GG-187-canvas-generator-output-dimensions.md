# GG-187 · 生成器完成后显示图片真实尺寸

- 状态：GG-116 本地实现，待站长在画布手验；未提交、未部署。
- 请求：生成器完成出图后，在节点右上角显示该图的真实像素宽×高，与现有图片节点的上沿元数据一致。
- 决策：沿用 GG-180 的生成器上沿和 GG-145 的图片尺寸样式。属于既有元数据展示扩展，不改变 ADR 0108 的生成、资产或项目保存决策。

## 范围与验收

- 仅成功且首张输出带有效像素宽高时，右上角显示 `宽×高`，并以“原始尺寸 … 像素”提供可访问名称；排队、生成中、失败、空白或尺寸缺失时不虚构数字。
- 沿用图片节点的上沿紧凑规则：宽度不足时优先收起生成器名称；极窄时只留类型图标，不让左右标签重叠。
- 多图生成时原生成器显示其首张图的尺寸，其他结果节点继续显示各自输出的尺寸。刷新或重开画布后，已保存的 job ID 重新读取授权任务及其资产尺寸，无需另存尺寸或重新生成。

## 实现与验证

- `server/generation/provider.mjs` 已用 Sharp 解码提供真实像素宽高；资产记录持久化 `pixel_width`/`pixel_height`，`publicGenerationJob` 作为 `outputs[].width/height` 返回。此次只修改 `canvas-generator-node.tsx` 的展示，不新增 API、迁移或图片读取。
- 按站长持续指示，不运行自动测试、构建或浏览器复测；仅做静态差异检查，由站长在 5173 `/canvas` 手验。未发起真实生图或付费请求。
- 下一步：站长确认已完成的生成器上沿右侧显示的像素尺寸，以及窄卡片时不与左侧图标相撞。

# 任务卡约定

一个实际需求一张卡，使用 [TEMPLATE.md](TEMPLATE.md)，标题 `GG-xxx` 保持唯一。
任务是 agent 维护的工作记忆，不要求站长填写。少写流水账，多写恢复所需事实。

- 状态：待办、实施中、待验收、待发布、已上线、已完成（不需上线）、搁置。
- 记录范围/非目标、验收、决定、分支与 worktree、实现/验证和明确下一步。
- 每个有意义的阶段更新，尤其在等待、压缩上下文或换窗口前。
- 成功/失败/跳过分别写；真实线上行为需要对应线上证据。
- 不保存用户邮件、完整资产标识、图片、提示词、密钥、Cookie、签名 URL、原始日志。
  用非敏感证据摘要和受保护记录名称。批准只记录动作/范围，不保存秘密。
- 一张卡只描述自己的任务；跨任务优先级见 `docs/BACKLOG.md`。
- 合并冲突时按 Git/验证记录协调真实状态，不能用新文档覆盖他人的未完工作。

完整历史计划在 `docs/history/`，无需复制进每张卡。

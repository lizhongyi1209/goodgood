# GG-129 — 画布图片移动指针与原比例缩放

- 状态：本地实现与门禁完成，待站长手动浏览器验收；未部署。沿用 `F:/goodgood-worktrees/GG-116` 的 `feature/GG-116-asset-history-actions` 分支，未切分支。
- 基线：GG-128 `186e074`；5173 继续提供热更新预览，32131 已验证 Web 与生产应用不因本任务替换。
- 请求：画布图片悬停使用“移动”指针，不显示抓手；图片卡片在画布中可缩放。
- 决策：扩展 [ADR 0109](../decisions/0109-quiet-canvas-image-hover.md)。悬停仍仅有浅灰反馈，选中后才显示一个灰阶缩放控制点。

## 验收

- 本地图片与生成结果的图片主体悬停和拖动均显示 `move` 指针；缩放控制点使用缩放指针，图片上不恢复原有操作按钮。
- 选中图片后可拖动右下角控制点按图片原始宽高比缩放；缩放只影响当前画布，图片内容不拉伸，节点仍可移动。
- 生成任务后续更新保留同一结果的已缩放尺寸；更换输出时重新按新图片比例初始化。
- 加载失败、生成中/失败、输入区参考图和生成流程保持原有状态；不自动上传、生成或持久化画布。

## 实现与验证

- 图片节点及子元素覆写 React Flow 默认的 `grab/grabbing` 为 `move`；已加载图片选中后才显示右下角近黑色 `NodeResizeControl`，保持宽高比，限定尺寸在 48–960 CSS px 范围内。
- 本地图片加载后按原始尺寸适配到最大 238 × 320 CSS px。生成结果也按图片真实尺寸适配；同一输出后续状态更新保留手动缩放尺寸，更换输出重置尺寸。卡片内容使用 `object-fit: contain`，不拉伸原图。

- 未进行浏览器交互验收、真实上传、付费生成、32131 检查点替换或生产部署。下一步由站长在现有 5173 `/canvas` 手动检查本地图与生成图的移动指针、选中控制点、原比例缩放和点击详情。

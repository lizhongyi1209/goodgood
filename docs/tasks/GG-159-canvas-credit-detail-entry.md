- 状态：本地界面已修改；待站长手动验收，未提交、未部署。
- 日期 / 工作区：2026-09-28；`F:/goodgood-worktrees/GG-116`，`feature/GG-116-asset-history-actions`。
- 用户需求：点击 `/canvas` 右上角的积分余额，打开大厅已有的账户管理/积分明细弹框；主标题由「用量」改为「积分明细」，今日/本周/本月消耗的数值不再附带「积分」二字。
- 决策：[ADR 0112 补充](../decisions/0112-account-credit-usage-dialog.md)，沿用现有弹框和私有账单接口，无新路由或计费行为。

## 范围与验收

- 画布顶部积分余额成为按钮，保持闪电和数值样式，鼠标与键盘均能打开既有弹框；Esc、关闭按钮、遮罩可关闭，回到原画布及节点状态。
- 弹框左栏「个人主页」仍可用；画布进入时指向现有 `/profile`。明细接口返回余额后同步画布右上角数字。
- 主标题统一为「积分明细」；三个周期消耗在标题下只显示数字，积分语义由页面与可访问名称提供。大厅入口复用同一变化。
- 登录/账单读取未完成或失败时不假装有余额；只读明细读取和失败恢复沿用原组件。原始账本、余额计算、生成、拖动逻辑不变。

## 实现与证据

- `features/canvas/canvas-page.tsx`：右上角余额改为原位按钮；已有 active 会话控制可用状态，读取中/失败显示 `--` 并保留明细入口。复用 `CreditUsageDialog`，用稳定回调把活动接口返回的账户摘要同步到画布账单状态；个人主页指向现有 `/profile`。
- `features/canvas/canvas-page.module.css`：保留原浅灰余额外形，增加轻悬停与可见键盘焦点。
- `features/billing/credit-activity-view.tsx` 与 `credit-usage-dialog.tsx`：共享主标题、可访问标题统一为「积分明细」；三个周期消耗移除视觉上的「积分」单位，数值仍带含单位的可访问名称。大厅与画布看到相同内容。
- 决策/边界：在 ADR 0112 补充画布入口。未新增路由、账单接口、支付/计费操作或节点状态副作用；32131 保持 GG-155 的 `b12f699` 后端检查点。

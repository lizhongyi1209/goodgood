# GG-183 — 画布视频预览贴合与移除帧率

- 状态：GG-116 本地已修改，待站长在画布手动验收；未提交、未部署。
- 请求：竖屏视频应完整占据自己的节点，选中蓝框贴合画面；暂时删掉无法可靠取得的 FPS 展示和解析。
- 决策：修订 [ADR 0108](../decisions/0108-standalone-canvas-image-generation.md#gg-183-addendum--video-preview-geometry-and-metadata-2026-09-29) 的 GG-146 FPS 与视频几何约定。保留尺寸、时长、播放、上传和等比缩放。

## 范围与验收

- 新拖入或从资产库拖入的视频，在 HTML 视频元数据就绪后，节点按原始宽高比显示完整画面，蓝色选中框与画面贴合。
- 项目恢复时不能把元数据未到之前保存的 238×158 占位框误认为已测量视频；已按真实比例缩放的节点保留当前尺寸。旧的不等比尺寸按原比例校正。
- 文件名左侧保持播放类型图标，右侧只显示原始像素尺寸；不再加载 MediaInfo WASM、解析、显示或写入 FPS。旧项目已有 FPS 字段仍可读取，后续保存时丢弃。
- 视频上传、悬停续播、时长、失败重试和画布图片/生成器行为不改变。

## 实现与验证

`canvas-video-node.tsx` 在元数据回调中按视频宽高比修正节点几何；`canvas-video-size.ts` 区分旧占位框、已等比缩放和旧不等比缩放。项目恢复仅把已匹配视频宽高比的尺寸视为已测量。移除 FPS UI、解析模块、WASM 声明及 npm 依赖；服务端允许旧字段输入但不再写回。

按站长持续指示，未运行自动测试、构建或浏览器复测；仅做静态差异检查。由站长在 5173 `/canvas` 手验竖屏视频、刷新恢复和旧视频节点。未触发真实上传或付费生成。

# GG-165 — 画布参考图添加入口移入预览区

- 状态：GG-116 本地未提交界面已修改，待站长手动验收；未部署。
- 请求：删除画布 chat 底部的「添加参考图」入口，在现有参考图预览区域提供可点击的添加卡片；按 2026-09-28 截图改成浅灰底、图像图标和「参考图」文案，并明确沿用真实上传接口。后续要求上传中复用画布图片的呼吸光，上传成功的卡片与入口同形。
- 决策：调整 GG-147 已确认的入口位置，已在 [ADR 0108](../decisions/0108-standalone-canvas-image-generation.md) 追加决定。只移动入口，不更改参考图数据、上传与生成边界。

## 范围与验收

- 预览区始终显示，零张图时也有约 54×68px 浅灰圆角「参考图」卡片；有图时入口跟在同样尺寸和圆角的居中裁剪缩略图后。点击继续使用原隐藏文件输入框选择 JPEG/PNG。`uploadReferenceFiles` 向 `/api/references` 请求上传意图、将文件 PUT 到服务端返回的地址、再调用 `/complete`；即时缩略图先读取本地 Blob，上传成功后引用服务端返回的素材 ID，失败显示重试。
- 真实上传进行时在清晰的预览图上叠加与画布拖入图片相同的轻暗遮罩和呼吸光；请求成功时去掉效果，保留同形缩略卡片及选中序号。减少动态效果偏好下只保留静态遮罩。达到十张上限时不显示添加入口；删除一张后重新出现。移除、失败重试和悬停完整预览保持。
- 底部工具栏只保留图像设置、模型与生成控件；窄屏工具栏随入口移除重排，不预留空白列。

## 验证与后续

按站长持续要求，不运行测试、构建、浏览器复测或真实上传/生成；仅做静态差异检查和接口调用链审阅。待站长在 `/canvas` 手验零张、一张和十张参考图的入口、文件选择、上传中呼吸光、成功后的卡片比例、实际上传失败/重试、删除后恢复入口及窄屏排列。5173 热更界面，32131 后端不需切换；生产未部署。

- 后续变更：GG-128 按 [ADR 0109](../decisions/0109-quiet-canvas-image-hover.md) 移除了本任务的本地节点悬停操作与预览弹框；GG-140 按 [ADR 0108 补充](../decisions/0108-standalone-canvas-image-generation.md) 撤下顶部文件选择和适应画布按钮。画布拖放、节点移动和输入区参考图选择仍保留；左下角缩放菜单仍有适合屏幕。

- 状态：本地实现与门禁完成，待站长手动浏览器验收；未部署。仅在 `F:/goodgood-worktrees/GG-116` 的现有 `feature/GG-116-asset-history-actions` 分支开发，未切分支。
- 基线：GG-125 `3612c88`，`/canvas` 已独立并接入现有图片生成。
- 请求：支持从电脑把图片拖入画布；顺手加入高频、轻量的画布操作。
- 决策关系：扩展 [ADR 0108](../decisions/0108-standalone-canvas-image-generation.md) 的临时节点与现有私有参考图边界，不改变已确认决定；无需新 ADR。

## 验收

- 拖入本地 JPEG/PNG，图片立刻在落点附近显示为可移动节点，按原比例预览；一次可拖多张。无效类型、空文件、超过 20 MiB 的文件有可见反馈，不能让浏览器导航离开画布。
- 顶部提供文件选择入口，便于键盘或无法拖放的设备使用；有节点时可适应视野。
- 本地图片节点可查看大图、明确加入现有生成参考图托盘，也可从本页画布移除。拖入本身不上传；加入参考图沿用登录、上限、上传状态、失败重试和清除流程。移除画布节点不删除已上传的私有资产。
- 纯白背景、现有生成能力和结果节点保持；不引入假数据、连线、画布保存或自动付费调用。

## 实现与证据

- `canvas-local-images.mjs` 复用私有图片 JPEG/PNG 与 20 MiB 限制，计算多图落点；`CanvasSourceNode` 即时显示本地对象 URL，支持预览、参考、移除与图片加载失败状态。画布页负责拖放、文件选择、适应视野与 URL 回收。生成节点更新继续保留本地节点。
- 定向 `gg125/gg126` 画布测试 5/5，通过文件接受/拒绝、空输入、双图落点和生成节点更新的共存路径；文档定向测试 11/11。最终 `npm run check:local` 590 项 / 567 通过 / 23 跳过 / 0 失败，Lint 0 错误、110 条既有警告；5173 `/canvas` HTTP 200。首次完整门禁在 BACKLOG 索引尚未更新时因文档链接检查失败，补齐后重跑通过。
- 没有自动执行真实文件上传、付费生成或浏览器验收。32131 已验证检查点和生产应用未替换，5173 沿用现有热更新服务。

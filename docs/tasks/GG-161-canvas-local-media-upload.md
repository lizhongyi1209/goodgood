## 范围与验收

- 有真实登录权限时，从电脑拖入本地 JPEG/PNG/MP4，立即显示本地预览；上传期间维持原位呼吸光，不显示「上传中」文字。完成时间取决于真实请求，不使用固定计时。
- 图片复用参考图登记、签名 PUT、完成与状态恢复接口；视频复用私有视频素材的同一组流程。图片完成后用 owner-scoped `/api/references/:id/content`，视频用素材列表返回的签名读取地址。完成后选择新节点，打开中的资产侧栏刷新；刷新资产库也可找到该素材。
- 失败保留文件和本地预览，节点说明原因并可重试。删除上传中的节点中止请求、释放 Blob URL；离开画布也中止未结束请求并释放 Blob URL。签名视频读取失败时从 owner-scoped 列表重新取得地址；仍失败则保留可理解的预览错误与重试入口。
- 已有资产从侧栏拖入、生成结果、音频、输入区参考图、节点坐标持久化、计费与生成 API 不因本任务改变。上传到资产库不代表保存画布布局。

## 实现与边界

- `features/canvas/canvas-page.tsx` 统一协调图片和视频节点的本地预览、真实上传、选中、侧栏刷新、失败重试和清理。
- `features/references/http-reference-upload.ts` 与 `features/creation/http-video-materials.ts` 向原有请求链增加可选 `AbortSignal`，现有调用方默认行为不变。
- 图片节点和视频节点共用上传中样式、失败提示；成功后只在远端预览加载成功时释放 Blob 作为过渡。视频签名 URL 过期时按需通过既有列表重新读取；如果当前页面仍无法取得可用签名，显示重试入口。无新后端接口或数据库迁移。
- 5173 前端热更可加载本地代码；32131 现有运行检查点已提供复用的上传和列表接口，但本任务未发送真实文件或验证端到端流程。`session.preview` 明确不进行私有上传。生产版本未改变。

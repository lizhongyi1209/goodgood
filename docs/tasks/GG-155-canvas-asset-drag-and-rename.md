## 范围与验收

- 图片、视频、音频列表行可以拖放至资产侧栏右边的可见画布，按落点新建临时节点；在侧栏内松开不新增。生成图片读已有原图 URL，上传图片/视频/音频沿用读取 URL；不重新上传、不调用生成模型、不计费、不存储画布布局。
- 图片/视频复用已有画布节点的原比例预览与移动，音频提供简洁原生播放节点。远程签名 URL 不参与本地 blob URL 回收。
- 缩略图和文件夹图标缩至 34px；缩略图居中裁剪，仅缩略图悬停/聚焦触发较大预览。文件名 hover 不触发预览，长名继续省略。
- 双击文件名或键盘 F2 原位编辑。Enter/失焦保存，Esc 取消；无效名和服务端失败保留输入并显示错误。生成及上传资产共用工作区/所有者范围内的显示别名；原文件名、存储对象与归档关系不变。`/assets` 页面重新加载时展示同一别名。
- 读取失败、资产无权访问、预览/播放失败不能创建重复文件或发起计费。演示会话继续不读取私有资产。

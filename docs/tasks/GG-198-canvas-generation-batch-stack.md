## 范围与验收

1. 新的 2/4 张画布生成结果全部由原图片生成器节点承载，拖动任意可见图片都移动同一批次，不产生可拆开的余图节点。
2. 点击生成图片只选择或切换画布内图片，不导航到资产详情；历史独立结果节点也移除资产详情链接。
3. 整批只显示生成器自身的一行类型名称与当前首图尺寸，后层图片不重复显示资产名和分辨率。
4. 图片不旋转、不抬升，按自然方向向右错位。悬停、聚焦或点击后层图片时，它与当前首图交换槽位，用短促位移动效说明层级切换。
5. 成功任务、所有输出资产、生成器尺寸、提示词参数、输入连线与项目恢复保持；旧项目中属于当前生成器同一任务的冗余余图节点在恢复或当前页面归一化时合并回生成器。

## 范围与验收

- 在同一个创作器中提供常驻 `图片 / 视频` 模式切换，默认图片模式。
- 图片与视频各自保留独立的会话内提示词、素材和参数；切换不影响正在运行的图片任务。
- 视频模型按 Seedance 2.5、2.0、2.0 Fast、2.0 Mini 排列，并按型号约束分辨率和时长。
- 视频参数包含画面比例、模型、分辨率、时长、声音；不显示图片生成数量和图片专属参数。
- 视频模式允许本地添加图片、视频和音频，展示类型、顺序、图片角色及可删除状态。
- 视频飞鸿操作不得调用图片 `/api/generations`，而应明确提示接口待接入并保留输入。
- 桌面与窄屏布局、键盘切换、可访问名称和图片模式回归通过。
- 不修改后端 API、数据库、计费、provider、生产配置或部署状态，不执行真实付费请求。

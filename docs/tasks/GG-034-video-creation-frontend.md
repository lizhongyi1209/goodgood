## 范围与验收

- 在同一个创作器中提供常驻 `图片 / 视频` 模式切换，默认图片模式。
- 图片与视频各自保留独立的会话内提示词、素材和参数；切换不影响正在运行的图片任务。
- 视频模型按 Seedance 2.5、2.0、2.0 Fast、2.0 Mini 排列，并按型号约束分辨率和时长。
- 视频参数包含画面比例、模型、生成模式、分辨率、时长、声音；不显示图片生成数量和图片专属参数。
- 生成模式默认 `多模态`：图片、视频和音频按模型能力共同受限；`首尾帧` 只允许最多两张图片，
  并按托盘顺序标记为首帧和尾帧。切换到不兼容模式时保留已有素材并提示先移除，不静默删除。
- 视频模式允许本地添加图片、视频和音频，也可从资产库选择图片、视频和音频；展示类型、顺序、
  模式决定的素材用途及可删除状态。
- 本地上传合并为一个 `上传素材` 入口，只接受当前模式允许的图片、视频和音频。普通上传不自动
  创建 provider 素材；`创建素材` 使用独立、默认零选择的前端流程，由用户决定需要创建的项目。
- 历史创建素材在正式提交视频前必须重新校验有效性；过期、被轮替或结果不确定时保留草稿、阻断
  提交并引导重新创建。接口到达前不得伪造素材 ID、有效状态或创建成功。
- 视频飞鸿操作不得调用图片 `/api/generations`，而应明确提示接口待接入并保留输入。
- 桌面与窄屏布局、键盘切换、可访问名称和图片模式回归通过。
- 不修改后端 API、数据库、计费、provider、生产配置或部署状态，不执行真实付费请求。

## 已上线的能力与边界

- Authing Google/邮箱验证码登录；后端验证身份，使用 GoodGood 自有会话。
- 注册人数不设上限；新账户 `pending`，发放 100 欢迎积分，审核后才能创作。
- 三种账户状态：`pending / active / suspended`。站长在 `/admin/users`
  审核、暂停账户及审计式补发测试积分；现有单次补发范围为 1–5000。
- Nano Banana 2：14 种产品宽高比 × `1K / 2K / 4K`，共 42 个组合。
  一次输出 1 张、10 积分。其他模型的 UI 名称不代表已接入；多输出未开放。
- 线上仍以 `标准 / 高清 / 超清` 展示分辨率，资产库尚未展示实际像素尺寸；
  GG-005 本地候选将修改该展示，生产事实以发布后的复验为准。
- 真实后端任务、积分预留/结算/失败处理、最多 10 张参考图、私有结果读取、
  资产库、项目保存恢复、创作草稿均已有实现；具体语义以对应代码/测试为准。
- 已确认 GG-004 可靠性缺陷：同一 queued job 可被 Web/Worker 重复派发并在单 Worker
  内并发执行，导致实际生成并上传私有 R2 的结果仍被记录为 `SUBMISSION_UNKNOWN`，
  数据库无 Asset 且积分被释放。修复已在本地阻止重复执行并校验终态提交；生产仍运行
  `94cecb0`，线上尚未修复，真实数据未做人工恢复。
- 保持香港现有服务器、现有私有 R2；支付/支付宝、自动账户删除、举报界面、
  Grafana/复杂监控及大规模上线配套暂缓。
- 不新增用户任务数或生成并发上限。持久队列用于可靠投递/恢复，不是人为串行限制。
  继续执行可用内存低于 500 MiB、根磁盘使用率达到 80% 的新生成保护。
- 站长只激活已亲自确认并告知测试边界的用户：非敏感素材、O1Key 处理、
  外部删除条款尚未齐备、站长提供线下反馈/暂停/精确目标人工处理渠道。
  这是 ADR 0024 的补偿措施，不得宣传完整隐私删除或付费服务保障已完成。

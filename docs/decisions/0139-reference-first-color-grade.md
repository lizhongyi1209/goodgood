# ADR 0139 · 参考图优先的自动校色

- 状态：Accepted（2026-10-03，用户确认默认先按参考图自动调整，再微调）

- 2026-10-03追加决定：用户要求此处不提供保存格式功能，按原图处理。移除格式选择；保存从原始文件字节识别JPEG/PNG，沿用实际格式及原像素尺寸，不默认转PNG或因20MiB上限切JPEG。超过原上传上限给出保存失败，保留调整参数；不新增压缩/换格式设置。未知原始编码明确暂不支持保存，不用文件名伪装格式。

画布图片快捷栏新增调色。打开后解析当前输出冻结输入中的实际参考图，
默认使用首张可用参考并自动校正整体色度偏移；用户可选择另一参考或资产。
没有参考时显示选择入口，读取失败可以重试，不用其他图悄悄替代。
自动结果作为初始状态，匹配强度默认100%，手动参数默认中性，可回到自动
结果或查看调整前。匹配主要处理色度，默认保留源图明暗结构，不声称最优
或恢复模型已改变的材质/局部颜色；极端转换使用有界色域映射。

预览在浏览器本地计算，最长边最多2048，保存按源图像素尺寸输出新副本，
沿既有受权读取/原文件上传和资产流程，不覆盖源图，不额外调用Provider、
改变积分或增加后端数据域。预览/导出共用变换，关闭/身份或页面变化取消
异步工作；错误保留当前参数，保存成功意味着本机副本已接入既有上传流程。

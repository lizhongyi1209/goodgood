# ADR 0119 — 项目页首位新建卡片

- Status: Accepted
- Date: 2026-10-01
- Task: [GG-243](../tasks/GG-243-project-create-card.md)

## Context

项目页目前用页头「新建创作」按钮进入大厅创作。用户明确要求入口改为卡片，放在所有项目之前，点击直接进入新画布。

## Decision

项目网格第一项固定为「新建项目」卡片，采用现有项目卡片的大小、浅灰外框、圆角和响应式列数，内有加号及简短标签。撤下该页面原页头新建按钮。列表为空、读取中或读取失败时入口仍可用。

入口使用现有 `/canvas` 路由，由既有 CanvasPage 新建独立空白项目、分配稳定 ID 并沿原本机与服务端保存流程持久化；没有预先命名步骤。现有项目入口、管理与失败重试继续沿用原接口。

## Consequences

这取代项目页旧「新建创作」位置和大厅目的地，不改变首页、大厅其它新建创作入口、画布内部功能、持久化契约或生产状态。创建与进入本身不请求模型、不扣积分。

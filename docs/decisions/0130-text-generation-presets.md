# ADR 0130 · 文本生成预设

- 日期：2026-10-02。
- 状态：已接受，源码与后端启用单列。
- 任务：[GG-297](../tasks/GG-297-text-generation-presets.md)。

文本生成chat在模型旁新增“预设”菜单；首项“结构化反推”，稳定ID structured_reverse。选择后输入区显示可移除的灰色Badge，只展示预设名称，不展示其完整指令；已有手写内容保留，可以作为附加内容，也可留空直接生成。取消标签回到原输入规则，预设随复制/项目保存恢复。

此项扩展ADR0127原仅模型的chat，沿用黑灰界面、模型/思考深度和ADR0129计费；不新增颜色方案或其他参数。

2026-10-02用户确认启用预设且无额外积分费用：预设生成仍共用普通文本生成的一次20积分预留/成功结算，不额外计费；中断10、系统失败0沿ADR0129。本地启用另记[GG-300](../tasks/GG-300-preset-activation.md)，生产不随本地启用改变。

指令仅在后端白名单中定义：根据图片生成JSON结构化中文提示词，包括主体描述、环境、光影、镜头语言、风格关键词。浏览器契约只含ID/名称和用户附加内容；后端在调用前将预设指令置于当前输入前，不接受客户端自定义预设指令或未知ID。历史和客户端项目不写入该隐藏指令，只记录用户输入与预设名称；服务端幂等快照包含解析后的输入与预设ID。

所有原有素材授权、长度限制及失败/停止规则保持。首版只提供一个预设，不强制用户填写额外文本，不改变模型路由。按用户约定仅开发，不自动构建/检查或真实生成；后端更新需要后续启用。

带预设的客户端请求使用/api/text-generation/preset-stream，与普通stream共享授权/结算实现；旧后端明确404并显示未启用，不会忽略预设后按普通输入发起计费调用。

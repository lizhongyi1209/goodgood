# ADR 0081 — JCOIN 分批定额与仅累计的第一期

- Status: Accepted
- Date: 2026-09-14
- Task: [GG-083](../tasks/GG-083-jcoin-batch-accumulation.md)
- 关联：[ADR0079](0079-jcoin-reward-planning.md)、[ADR0080](0080-classified-admin-credit-grants-and-operations.md)。本ADR接受发行结构/一期边界，不接受具体额度或倍率。

## Context

用户同意分期指定有限发放总额：没有截止日期，本期发完才再开启下一批。用户明确否决兑换积分，上市之前暂不考虑任何兑换，第一期仅充值消费挖矿并累计；不得锚定可能的人民币价值。前次GG082兑换建议和GG080自动跨阶段建议据此不再适用。

## Decision

- JCOIN总上限100,000,000，用户回馈50,000,000，消费驱动及2026-09-18北京时间00:00原成功结算起算保持不变；充值到账本身不挖矿。
- 每批指定并锁定发放限额，没有发完期限或固定每日释放量。当前批次发完后结束，下一批需另行开启，不能自动跨批分段发放。具体批次额度和开启参数仍待接受。
- 第一期只有符合资格的充值来源消费奖励及用户累计余额/奖励记录。不提供积分、现金或其他权益兑换；未来用途/上市安排不构成一期承诺或预设上线计划。
- 不设币价、人民币估值、兑付面值、兑换汇率或发行价。消费计算比例仅决定获得枚数，与币的人民币价值无关；页面不显示金额等值或返现比例。
- 用户倾向消费越多获币越多。建议同一批次采用固定比例线性累计；此处确认的是意图，具体公式/比例和是否档位加成仍待讨论，不默认为已接受某个倍率。
- 20%创作安排继续保留未启动，分母/含义和完整子池仍未确定。每批占用现有回馈库存，不借另一50%或擅自取消创作预留。

## Consequences

GG082积分兑换/服务面值试算被否决，不用于初始倍率决策。分发库存、账户、不可变奖励/退款流水、幂等、额度封顶及批次状态仍需实现；当前没有发行运行时。

本期倍率锁定、最后一笔只发剩余额度、退款回收不自动重开本期以及两批间消费是否补发，见[GG083讨论](../research/GG-083-jcoin-batch-accumulation.md)，均为待接受的执行建议。首期100万枚和示例每100有效积分10枚未获明确数值确认。

本轮仅整理产品决定和讨论建议，不迁移/写真实数据，不公开发行或部署；实施范围与发布分别记录。

# ADR 0063 — 模型管理与人民币分币积分

- Status: Accepted
- Date: 2026-09-13
- Task: [GG-052](../tasks/GG-052-model-management.md)
- Supersedes: ADR 0009、0029、0047 中的旧积分数量；延续 [ADR 0062](0062-rmb-anchored-specification-pricing.md) 的销售计量规则。

用户确认按新积分基础实施站长模型管理并在页面尝试定价。1 元人民币对应 100 积分，1 积分对应 1 分。图片按分辨率的每张售价，视频按分辨率的输出秒价和参考视频输入秒价，不以不可预测的上游 token 成本向创作者事后补扣。

旧单位 `credit` 与新单位 `credit-cny-cent` 区分。转换创建新账户和带旧账户来源的新账本入账，旧账户关闭但保留原记录；旧余额及可划拨充值来源余额乘二。不可变历史价格、流水、订单和任务报价不重写。企业账户、成员额度及已用额度等值转换并保存转换前快照。迁移遇到活动任务、预留或待支付订单时失败，要求先排空；生产迁移另属发布授权。

初始图片售价保持人民币价值：普通图片 0.20 元/张，Pro 0.30 元/张。新欢迎积分 200，10 元充值产品 1000 积分。视频没有经过成本核验的默认售价，保持禁用，站长填完整规格价格后才可启用目录。

模型目录与已接入模板分离。站长可新增采用现有图片/视频模板的模型条目、修改展示信息和规格价、启用/禁用。添加条目复用模板的既有服务端模型线路，不接受浏览器配置秘密或任意上游 URL。新上游协议仍需适配代码。禁用阻止新提交，不取消已受理任务；价格发布产生新不可变版本，旧任务继续按接受时的版本结算。

本任务完成图片目录、报价和正式账本的联动；视频面板提供秒价配置和试算，原本地视频预览仍不扣积分，正式视频持久化和结算不在此任务偷偷扩展。

# ADR 0001: Image-first creation workspace

- Status: Accepted
- Date: 2026-08-27

## Context

Early editorial and technical dashboard directions made the product feel like a
magazine or model console. The primary user task is repeated visual creation and
comparison.

## Decision

The first viewport is a working creation surface with a compact composer and an
image-led result stream. Empty state remains restrained. Parameters stay in an
attached drawer and records remain secondary to images.

## Consequences

- Visual output receives most screen area.
- Marketing/editorial hero patterns do not enter the signed-in workspace.
- Advanced controls must justify their presence and remain collapsible.

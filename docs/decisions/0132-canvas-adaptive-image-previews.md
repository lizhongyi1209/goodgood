# ADR 0132 · 画布按需最高2K图片预览

- 日期：2026-10-02；状态：已接受，源码与后端启用单列。
- 任务：[GG-306](../tasks/GG-306-canvas-adaptive-preview.md)；扩展ADR0101的画布显示场景。

画布图片平时显示最长边512px、WebP quality80预览；GG-312按用户后续决定，以实际画布缩放达到300%（zoom>=3）作为高清门槛，取代GG-306原显示尺寸/像素密度的提前触发。视口内/附近且允许高清的图片在门槛上稳定180ms后按需切换最长边2048px、WebP quality90高清预览。节点拉伸及屏幕像素密度不改变门槛；低于300%立即显示保留的512预览。比例与透明度保持，小原图不放大。资产拖入、上传完成的图片与生成结果共用策略；未上传的本地图片仅在浏览器生成有相同上限的显示副本，上传仍用原File。

高清读接口只提供固定2048档，沿用所有权/工作区/素材可见性校验，不提供任意变换或绕过鉴权的原图回退。资产列表和附件继续用512档；原文件、下载、裁剪、生成参数/素材输入不变，不新增模型调用或积分费用。

高清加载期间保留已显示图像，向上跨门槛的稳定等待及既有缓存避免滚轮过程重复加载；不再使用420/560像素迟滞，视口外及隐藏叠图不请求高清。缓存只属于当前画布身份，限制并发、共享相同素材请求并回收闲置对象URL。实际图片像素元数据独立于显示副本，不用512/2048的naturalWidth改写原尺寸。按用户约定不自动构建/验证，后端启用另记；GG-312仅前端条件变化，无须重新启用后端。

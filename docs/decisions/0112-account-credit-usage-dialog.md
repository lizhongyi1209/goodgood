# ADR 0112：头像菜单内查看个人积分用量

- 状态：已接受，本地实现待验收
- 日期：2026-09-28
- 关联任务：GG-156
- 调整：GG-025 的大厅侧栏积分记录入口和独立页主入口

## 背景

大厅已经有账户头像菜单及个人积分余额。独立的侧栏“积分记录”与账户信息分离，占用图标栏空间。站长希望从头像菜单的“积分”进入页面内弹框，参考账户管理侧栏与用量表布局，并且不显示未实际扣除的退回记录。

## 决定

- 大厅移除左侧“积分记录”入口。头像菜单的积分行显示当前可用数额，整行可点击，在当前页面打开积分用量弹框。移动端的余额入口进入同一个弹框。
- 弹框使用现有私有积分活动接口，保留今日、本周、本月消耗和按时间分页的明细。筛选只提供全部、消费、获得三种业务类别。界面不提供充值、订阅或支付入口。
- GG-157 细化用量表：左侧导航命名为「积分明细」；筛选入口放入明细表第二列表头，默认显示「全部」，可切换「已消耗 / 已获取」。表格上方不重复放置分类控件，加载、空状态和错误状态仍可操作筛选。
- GG-159 将同一个弹框开放给独立 `/canvas` 右上角积分余额按钮，不新增画布内账单实现；主区标题也统一为「积分明细」，今日/本周/本月消耗仅显示数值。画布节点和创作状态不因打开、关闭弹框而改变。
- 业务投影中的 `released`（预留释放、未扣款）和 `refunded`（退回）不进入用量展示。原始账本、余额和结算计算不删改。接口旧 `return` 筛选可保留作兼容，不在新界面使用。
- 已发布的 `/credits` 路由保留作历史深链接；新大厅入口不导航过去，不因此丢失创作状态。

## 影响

积分消费明细归到个人账户入口；弹框关闭后回到原页面。原始财务记录仍可审计，隐藏仅作用于用户用量投影。

## GG-248 补充 — 默认个人信息（2026-10-01）

共享账户管理弹窗导航按「个人信息 → 个人主页 → 积分明细」，每次打开默认个人信息。展示真实头像、昵称、用户名、只读登录邮箱、用户 ID 和邀请码，后两项可复制；资料编辑继续既有个人主页流程。积分明细改为显式切换后读取，余额、账本、原接口与返回当前创作页行为保持。见 [任务](../tasks/GG-248-account-personal-information.md)。

# ADR 0073 — 模型卡片与右侧价格面板

- Status: Accepted
- Date: 2026-09-14
- Task: [GG-070](../tasks/GG-070-model-cards.md)
- Supersedes: ADR 0063/0069/0071 的目录价格行展示；定价语义不变。

用户要求避免模型增长使逐线路规格表过长。目录改响应式卡片，图片/视频分组保留。卡片展示默认线路价格范围而不是最低其他线路价格，不暗示禁用线路可用；视频无/有参考两档明确分开且单位不混。支持规格和线路数量方便识别，完整质量矩阵不放目录。搜索、筛选、快速启禁、Seedance2.5优先不变。

点击卡片在当前页右侧打开现有定价编辑功能，不增子路由或第二层价格弹窗；添加也使用同一Sheet。宽屏约760px，窄屏全宽，内容内部滚动、保存固定可达；Radix处理焦点、Esc、遮罩和关闭，保存中禁止关闭。取消不改配置。删掉重复线路/价格介绍及页面脚注；保留人民币积分锚定、折扣基准、必要单位与质量/视频结算规则。不改变后台持久化/真实模型能力，不发付费请求或部署。

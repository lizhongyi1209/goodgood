# 0144 — 设计系统 v3：中性界面，蓝色只代表积分

- 状态：已接受（用户于 2026-10-10 明确确认，GG-423）
- 日期：2026-10-10
- 取代：ADR 0002 的宫廷红交互配色；更新 ADR 0105 的全面无彩色限制，允许积分蓝色。
- 范围：设计规范全局成立，代码按页面迁移；GG-423 只迁移首页，其他页面暂保留现有样式及已接受的画布例外。

## 背景

GG-422 从 336f24a 接入设计文档及 --ds token，未迁移页面。用户现已接受中性界面、黑色主操作、蓝色只代表积分，并明确停用宫廷红。本次从设计分支 5e404e2 接续，按「先界面、后功能」实现首页。

## 决定

- 黑字白底与中性灰；主操作为 action 黑色，悬停、选中和错误状态使用灰度与文字/图标。蓝色 accent 只用于积分相关展示，不能用于普通导航、发送或其他主操作。
- 规范以 [docs/design](../design/README.md) 为准；数值以 tokens.json 和 app/design-tokens.css 的 --ds-* 为同一来源，不一次性替换旧页面变量。
- 首页输入面板为素材行在上、提示词在中、模式与向上箭头发送在下；不放参数或抽屉。提交使用现有默认/上次参数，进入现有生成视图；参数仍在原生成视图调整。
- 素材上传/拖放/粘贴/从资产选择及已存在的链接读取复用现有边界；素材上限按实际模式与模型契约，图片最多 10 张。不因展示稿重写业务上限。
- 新发送按钮用向上箭头，旧飞鸿发送图标不用于迁移后的输入面板；品牌标志继续复用现有资产。
- 先完成展示层和响应式布局，再接已有导航、账户、上传、图片/视频生成；不新增后端接口。

## 本轮功能边界

- GG-073 灵感案例已在 GG-117/ADR 0104 整体退役，当前无组件/API；不恢复旧路由、数据库或服务。
- VITE_GG_HOME_DEMO 默认关闭，且生产构建强制关闭。只在本地开发显式打开后显示常用模板、灵感示例及批量/对话入口；示例数据独立文件、后续换真实接口，不自动提交生成。
- 公告已有 GG-340 真实功能，沿用现有公告中心与权限，不受示例开关控制。
- 手机「我的」打开现有账户菜单，站长/企业/分销管理按原权限放入菜单。

# 0144 — 设计系统 v3：中性界面，蓝色只代表积分

- 状态：提议中（GG-422）
- 日期：2026-10-09
- 范围：界面配色、组件与页面规范的目标状态；本 ADR 只登记文档与并存 token，不切换现有页面。

## 背景

来源提交 336f24a 在独立设计分支整理了首页、创作页（图片 / 视频 / 批量）、对话、资产等页面与 33 个组件。GG-422 将其接入 GG-421 的现行白色、无彩色画布；当前 ADR 0105 已禁止一般彩色强调，ADR 0110/0108/0141 等允许画布选中轮廓、连线与图像注释的特定例外。本 ADR 仍是目标提议，接入文档不代表接受配色或迁移现有页面。

## 决定（提议）

- 界面以黑字白底与中性灰为主：主操作为近黑色 `action`，交互状态只改灰度填充，错误不用红色。
- 唯一的彩色 `accent`（`#2754d9`）只用于积分与付费（余额胶囊、充值、积分提示条）。
- 规范与数值以 [`docs/design/`](../design/README.md) 为准；数值以 `--ds-*` 前缀写入 `app/design-tokens.css`，与现有变量并存。
- 迁移按页面进行：迁移某页时把该页使用的旧变量和写死的值改为 `--ds-*`，不做一次性全局替换。

## 影响

- 后续若接受积分蓝色提议，需先审查并同步 ADR 0105、AGENTS.md 和相关范围例外；本轮不改变已接受决定。
- 接受前，现有白色、无彩色页面与已接受的画布范围例外保持；新文档只作为目标规范。

# 0144 — 设计系统 v3：中性界面，蓝色只代表积分

- 状态：提议中（GG-405）
- 日期：2026-10-09
- 范围：界面配色、组件与页面规范的目标状态；本 ADR 只登记文档与并存 token，不切换现有页面。

## 背景

main 的强调色仍是 ADR 0002 的宫廷红，用在当前导航、按钮、焦点、错误等多处，颜色同时承担"选中""主操作""错误""积分"几种含义。设计快照分支 `design/gg-402-frontend-snapshot` 的 ADR 0105 已提出去掉彩色强调；随后在设计画布中完成了首页、创作页（图片 / 视频 / 批量）、对话、资产等页面与 33 个组件的统一设计。

## 决定（提议）

- 界面以黑字白底与中性灰为主：主操作为近黑色 `action`，交互状态只改灰度填充，错误不用红色。
- 唯一的彩色 `accent`（`#2754d9`）只用于积分与付费（余额胶囊、充值、积分提示条）。
- 规范与数值以 [`docs/design/`](../design/README.md) 为准；数值以 `--ds-*` 前缀写入 `app/design-tokens.css`，与现有变量并存。
- 迁移按页面进行：迁移某页时把该页使用的旧变量和写死的值改为 `--ds-*`，不做一次性全局替换。

## 影响

- 接受后需同步修改 AGENTS.md 的视觉约束（宫廷红主色、禁止蓝色作为主色的条目）与 ADR 0002 的状态。
- 接受前，现有页面保持宫廷红；新文档只作为目标规范。

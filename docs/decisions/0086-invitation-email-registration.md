# ADR 0086 — 邮箱与邀请码共同注册

- 状态：Accepted；日期：2026-09-14；任务：GG-090。
- 替代ADR0045/早期账户准入中“首次邮箱验证自动pending注册并等待审核”的入口；邮件服务、浏览器绑定与验证码安全保持。

用户要求邮件码有效且邀请码有效才能成功注册，不再等待审核。实现采用已说明默认规则：活动站长在账户管理生成单人邀请码，可停用，不自动过期。后续如需多人码另行改变规则。

- 已有active账户仅验证邮箱登录；新账户必须同时通过未过期/未用邮件码及活动未用邀请码，事务内创建active member账户、一次欢迎积分、使用记录与会话。无邀请码不得创建用户或发会话。
- 已有pending邮箱账户可新验证邮箱并使用邀请码变为active，不新建用户、不重复欢迎积分；旧状态不批量修改。已有pending会话通过邀请码开通表单重新验证邮箱。suspended仅能读既有状态，邀请码不能恢复暂停。
- 邀请码随机高熵，数据库仅存SHA256摘要/末6位提示，明文只在生成成功响应显示一次，管理员复制后自行发给受邀人；不发送邮件、写URL/localStorage或日志。生成采用唯一操作键，丢失生成响应须停用该码后再生成，重试不重复生成且不再返回明文。
- 活动站长在数据库重新鉴权，生成/停用同事务；邀请码行锁保护仅一个账户成功使用。停用与使用串行；不得覆盖已用码。使用绑定owner/challenge，不授予站长或企业身份。
- 邮箱是否已注册在有效邮件码后才判断。验证码错误不查询/消耗邀请码；无效邀请码保留正确邮件码可重试，并计入挑战失败上限/现有限流；缺少邀请码提示补填，不泄露是否存在具体码。全部失败无注册/积分/会话半成品。
- 历史OIDC只能登录已绑定账户，不再自动创建账户，指引新用户使用邮箱邀请码注册；local模式仅用于已有本地身份测试，不增加注册后门。
- 本地实现/隔离无Worker测试与本地原预览更新授权；生产变更、真实邮件或provider请求未授权。原32141仍为local模式，真实注册UI使用命名隔离SMTP测试栈验收，不把原预览改为真实发信。

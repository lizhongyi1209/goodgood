# ADR 0129 · 文本生成中断半价

- 日期：2026-10-02。
- 状态：已接受；源码实现与本地运行启用分别记录。
- 任务：[GG-296](../tasks/GG-296-text-cancel-half-credit.md)。

用户要求避免中途反复获取输出再停止以免扣费。文本生成固定价格仍为20积分；已经预留的请求被用户主动停止、刷新/切页/卸载或连接断开，按取消结算10积分并返还10积分。预留前校验失败不收费；提供商/系统失败与服务中断后的过期回收仍全退。成功终态扣20，即使前端尚在展示最后一段动画；重复取消、读状态或重用请求ID不额外扣费，也不重新调用提供商。

此项取代ADR0127的取消全退条款，其余模型/输入/编辑/20积分成功价格保持。不追扣历史已取消请求。取消保留已收到输出。

用户追加决定：主动停止后左下角不展示“已停止生成”或费用解释，恢复已取消请求也不显示该解释；停止控制在操作前提示中断费用，账本/API保留真实结算。实际生成失败继续显示错误。

后端是结算权威，不依赖客户端费用判断。完整关闭原预留，再在同一事务关联结算返还差额，保持账本唯一关闭及资金来源；企业同步成员已用额度和退款，已关闭成员额度的返还归企业可用余额。任务行锁和终态检查确保成功/取消竞态只有一个终态生效。API返回实际扣费金额，停止提示取服务端结果。

新增0062迁移仅扩展退款/实际扣费记录，禁止改动已执行0061、追扣旧记录或恢复已撤回GG-292。按用户默认只开发约定，本轮不自动构建/检查、执行迁移、重启服务或真实生成；运行启用另记。

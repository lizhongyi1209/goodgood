# ADR 0085 — 私有问题反馈与站长处理

- 状态：Accepted；日期：2026-09-14；任务：GG-087。
- 接续：a73835f累计候选与GG084—GG086，不恢复旧C6。

用户要求在帮助下方增加问题反馈，支持最多5张图片、类型、信息和状态/回复。

## 决定

- 个人/feedback查看及提交自己的反馈；登录账户（包含待审核/暂停账户）可联系站长，反馈权限不赋予生成、积分或其他管理能力。预览会话不可提交。
- 类型：generation/account/billing/assets/suggestion/other；状态open/processing/resolved/closed，由站长管理更新。类型标签与领域值分离。
- 信息1—4000字符，最多5张JPEG/PNG/WebP图片，单张10MB；沿用完整解码及64—8192像素/4000万像素上限。浏览器multipart提交GoodGood，服务端校验后写专用私有对象；不进入资产库/项目，不调用provider。
- 用户只能读自己的反馈/图片；活动site_owner在/admin/feedback查看用户反馈、更新状态和追加回复。企业管理员/成员/分销身份不获得反馈访问权。
- 创建及管理写入有动作header、内容指纹与幂等键。站长回复携带版本，冲突须刷新；回复和状态历史追加保存，不覆盖原信息。
- 每账户24小时最多20条反馈，防止重复提交消耗本地/对象资源；幂等重试先返回原记录。列表每页20条按创建时间/ID游标读取。
- 图片与反馈同一提交，不设置独立未提交上传区。正常失败回滚并删除本次不可达对象；COMMIT结果不明时先核验反馈存在性，不删除可达图片，核验失败保留对象供运维检查。

## 边界

这次新增了已确认的私有支持功能，补充原产品能力范围；没有改变创作或JCOIN决策。
不提供举报/内容处置中心、公开反馈墙、邮件推送、用户追加对话、删除承诺或生产部署。
状态与回复通过页面刷新读取；用户提交的信息和图片只供本人及站长查看。

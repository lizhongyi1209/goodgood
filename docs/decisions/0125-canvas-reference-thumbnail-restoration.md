# ADR 0125 · 图片生成器恢复参考图缩略与悬停预览

- 日期：2026-10-02
- 状态：已接受
- 任务：[GG-276](../tasks/GG-276-restore-reference-previews.md)

用户澄清GG-273的参考图片展示理解有误，要求先恢复改动前的上传缩略和预览。

图片生成器的直接上传与连线图片恢复真实图片缩略图、序号及悬停/键盘焦点放大预览，复用既有Attachment、Tooltip和私有图片读取。GG-276恢复原54×68px缩略与添加入口、上传状态、失败重试及移除；GG-277按用户后继要求将缩略与添加入口改为54×54px正方形，原图和放大预览保持。

本决定仅取代ADR0124/GG-273的图片使用文件图标卡部分。文本文件卡、视频附件、Markdown编辑器、唯一混合输入端口、项目保存和后端输入验证均保持。

GG-278按用户后继要求移除添加入口的可见“参考图”文字，仅保留图标和既有可访问名称，54×54px正方形及上传行为保持。

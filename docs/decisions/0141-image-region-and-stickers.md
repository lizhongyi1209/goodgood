# ADR 0141 · 图片框选标注与贴图编辑

- 日期：2026-10-03；状态：接受，GG-352；GG-354修订原图编辑，2026-10-04/GG-359按用户要求改为红框副本。
- 用户要求图片快捷功能新增框选、取得bbox用于提示词定位；新增贴图，额外图片置于原图上层，支持移动、缩放、旋转及编辑时原图缩放。
- 这是现有本地图片编辑能力的新增范围，不替代裁剪/调色/添加数据/去除AI。界面沿Impeccable Operate和既有白灰图片编辑弹框，不改变视觉体系。

## 决定

1. 快捷栏新增独立「框选」「贴图」。共享受权原图读取、实际输出ID和当前节点/页/身份校验；原图就绪后编辑，关闭丢弃临时状态。
2. 框选直接在画布原图上操作，不单独打开弹框。加载后默认出现居中红框，图内简短编辑提示、外圈和选区外浅灰遮罩明确编辑状态；可重新画框、移动/四角调节，反向或超出图片时正确夹取，随画布缩放/平移对齐原图。右侧正常只保留「取消」「确认」，暂时移除bbox显示及复制。红色仅用于用户要求的图片标注/对应调节柄，不扩大界面强调色；图内提示、遮罩及调节柄不进入导出图片。
3. 贴图允许添加多张本地JPEG/PNG/WebP或已有受权图片资产，上层透明图片保留透明度；可选择层、移动、四角等比缩放、旋转柄/数值旋转、调整前后层级/删除。上层最大10张，单文件20MiB，拒绝损坏/超大解码图，失败保留已有图层。
4. 原图放大缩小先按编辑视图的缩放/平移实现，输出固定原图像素尺寸；已通过异步问题给用户区分视图缩放与改变原图合成构图，后者只有用户选定时调整此条。缩放围绕光标、适应画面、按钮/键盘等价入口，变换统一使用原图像素坐标。
5. 框选确认在浏览器将红色边框写入原尺寸PNG副本，预览与导出使用同一原图像素标注几何；保留原图、不裁剪、不写入bbox。贴图确认合成原尺寸PNG副本，透明度/旋转/层级与预览一致，超出原图范围部分裁去。两者复用旁置副本上传/项目/资产保存，不新增生成请求、计费、API或后台迁移。本地PNG合成不宣称保留原EXIF/凭证或原JPEG压缩字节。
6. 加载/空态/错误/取消、焦点回入口、触屏与键盘、切页/身份及源图替换取消、URL及解码资源释放是本功能范围；沿GG-276只写回归来源，不自动执行构建/检查/测试/浏览器验收。

## 验收

框选进入即显示可调红框及编辑提示，反向拖动/边缘/缩放保持对齐，右侧正常仅取消/确认；确认产生带红框的原尺寸副本，取消不保存，空框/未就绪不能确认。贴图来源/透明/多层/缩放旋转/底图视图缩放可操作，输出尺寸和预览构图一致，新副本可下载，失败保留草稿，关闭/换页不污染其他图片。

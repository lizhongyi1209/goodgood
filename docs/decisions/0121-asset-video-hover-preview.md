# ADR 0121 — 大厅资产页视频由鼠标 hover 触发预览

- Status: Accepted
- Date: 2026-10-01
- Task: [GG-246](../tasks/GG-246-asset-video-hover.md)
- Supersedes: ADR 0106 中大厅视频卡片进入可见区域即自动播放的规则。

## Context

用户要求大厅资产页的视频默认不播放，鼠标 hover 时才播放，并在静止画面中央显示播放图标。另一会话正开发画布资产面板，其行为由 ADR 0120 单独记录。

## Decision

- `/assets` 的网格和列表视频缩略图默认暂停，中心播放图标仅作媒体类型与暂停状态提示，不增加嵌套按钮或额外点击动作。
- 真实鼠标进入视频预览区域才请求静音循环播放；只有视频实际播放后隐藏图标。触屏或键盘焦点不触发卡片自动播放。
- 移开、离屏、页面隐藏、卡片禁用或卸载时暂停；保持减少动态效果设置，不让延迟加载或过期的 play Promise 恢复无人 hover 的视频。
- 播放被浏览器拒绝或加载失败时保持图标和现有点击打开预览入口；不新增错误横幅。
- 点击卡片打开的明确媒体预览沿用当前操作，图片、音频、尺寸比例、菜单、选择和上传行为保持既有约定。
- 画布资产面板及节点不在此变更范围。无持久化、后端、依赖、计费或生产变化；浏览器产品验收由用户完成。

## Consequences

可见性是允许播放的必要条件，鼠标 hover 才是触发条件。资源预览的暂停状态可被直接辨识，且资产页不再同时自动播放多段可见视频。

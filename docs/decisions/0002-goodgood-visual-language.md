# ADR 0002: GoodGood visual language

- Status: Accepted
- Date: 2026-08-27

## Context

Neo-Tech, blue accents, magazine linework, warm ivory, heavy separation, and a
plain text wordmark did not match the intended global premium visual identity.

## Decision

Use a light continuous canvas, Palace Red material accent, rounded compact
controls, minimal borders/shadows, the Double G mark, custom GoodGood wordmark,
and Feihong send symbol.

## Consequences

- Palace Red is an interaction accent, not a page background.
- Sidebar and work area remain visually continuous.
- Rebranding requires deliberate asset/token migration, not local CSS changes.

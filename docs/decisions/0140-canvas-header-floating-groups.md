# ADR 0140 · 画布顶部白色悬浮分组

- 状态：Accepted（2026-10-03，用户在GG-351方案后要求「试下看看」）

顶部导航由透明散列控件改成左右两组不透明白底/细浅灰边/12px圆角。
左组品牌、画布名称、分隔和页面，右组保存、积分、公告；中间仍透出画布，
不建立横贯屏幕的固定顶栏，不改变画布viewport/节点坐标或侧栏边界。
保留既有GG-219字号/图标、GG-230桌面25px中心线及按钮业务；页签选中灰底。
多页横向滚动，名称可截断/原位编辑；窄屏左组内两行，右组独立对齐顶部，
不挤压或叠放，公告未读/菜单/保存重试/键盘和触屏行为保持。

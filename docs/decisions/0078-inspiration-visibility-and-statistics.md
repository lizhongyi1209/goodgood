# ADR 0078 — 灵感参数可见性与互动统计

- 状态：Accepted，2026-09-14，GG-077；扩展 ADR 0077。
- 参数可见性提供公开全部、仅隐藏提示词、隐藏参数和提示词三档。旧公开/隐藏提示词案例保持原行为。
- 完全隐藏案例的详情和复刻 DTO 不提供原参数与提示词；后端读取固定参数生成，用户只提交自己的参考图、可为空的补充和报价版本。公开和仅隐藏提示词仍可修改参数。
- 私有生成记录保留隐藏标记，任务读取和资产库使用统一脱敏投影；Worker 和失败重试继续读取后端实际参数，费用按实际参数预留/结算。图片实际尺寸属于可观察的输出，不承诺隐藏图片本身可推断的属性。站长查账后台仍保留真实计费上下文。
- 大厅展示查看数、使用数和点赞数。打开详情成功记查看，成功载入复刻配置记使用；包括作者自己的操作，不是独立访客或生成成功次数。列表、划过对比、报价刷新、失败不增加。
- 每次打开/使用分配交互 UUID，按案例、用户、动作去重；客户端重发、React effect 重入和从大厅进入预设页不重复计数。新的一次打开或使用仍计数。
- 增量迁移保存旧数据，计数从零开始，不追溯历史。没有公开个人主页、好友或生产部署变化。
- GG-078（2026-09-14）按用户后续要求：大厅与详情取消点赞入口，大厅查看/使用并排，仅显示图标和数字，以无障碍名称说明含义；历史点赞记录保留，统计规则不变。此条替代上面的点赞展示约定。
- GG-079（2026-09-14）用户澄清：点赞必须保留，恢复大厅与详情点赞入口；大厅点赞/查看/使用同一行，只显示图标与数字。灵感详情的效果与对比图片在内容区域水平居中，原比例、默认处理后、交互与访问边界保持。此条替代 GG-078 的取消点赞约定。

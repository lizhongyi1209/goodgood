# ADR 0079 — JCOIN 奖励规划与决策边界

- Status: Proposed
- Date: 2026-09-14
- Task: [GG-080](../tasks/GG-080-jcoin-planning.md)
- 关联：ADR 0043 的充值来源、ADR 0060 的业务身份、ADR 0063 的人民币积分、ADR 0074 的运营统计。

## 已由用户确定

名称为 JCOIN，总量固定上限100,000,000，其中50,000,000用于用户回馈；早期只奖励消费中的充值部分。用户确认发行速度由平台真实消费决定，不按时间固定释放，从2026-09-18开始起算；按现有北京时间账期具体为当天00:00，按成功结算时间判断。

最新提出回馈安排中20%用于“平台创作利益”；20%的分母（总量或回馈池）和含义（独立激励池或权益用途等）待澄清，因此消费子池不能继续默认占满5000万。创作部分先保留未释放；当前工作从a73835f及规划78e4c40继续，无发币。

后台增加积分需结构化类型选择，备注不定义资金来源。充值有证据且与付费来源关联，赠送/活动/测试/普通补偿/其他不具有消费奖励资格。选项具体列表及受限浏览器充值登记实现仍在规划；现有test-credit-grants即使备注写充值也仍是赠送。

这是对现有单一消费积分体系的扩展。JCOIN 与 `credit-cny-cent` 分账，现有 100 积分/CNY 和已受理任务报价不因规划改变。充值、赠送、划拨、预扣和成功结算必须继续保持不同业务含义。

## 建议，尚未批准

第一阶段建议采用平台内权益奖励，不承诺现金兑换、投资收益、交易或未来上链。消费驱动方向已确认，具体倍率/阶段尚未确认；按净充值来源成功消费计算奖励，建议以累计有效消费进入递减阶段，使用固定总量库存和独立不可变奖励流水。剩余50%保留未分配；20%定义、用途/兑换、阶段参数和企业受益主体需进一步确认。旧充值余额在起算后消费有资格，起算前消费不补发；实施晚于起算时可重放起算后证据，具体执行另属实现/发布。

个人资金消费建议奖励消费账户；企业资金消费建议奖励企业钱包而非操作员工。企业来源识别和企业钱包需要先实现，现有成员额度流水不能当作第二次消费。当前无正式结算的视频预览不参与分发。

完整规则、示例参数、退款与配额处理见 [分发规划](../research/GG-080-jcoin-distribution-plan.md)。本 ADR 仍为 Proposed，不授权迁移、实际发币、公开承诺、收款或部署。

## 管理端关联

原请求接受的方向是默认运营看板、充值指标、提交量改并发；本阶段未实施。当前处理中含排队，不能改个名称就当并发；需明确当前与每日峰值、后端图片统计和未持久视频的边界。

结构化充值登记将改变ADR0010/0043的操作命令专用边界；实施时应另补受限站长入账ADR及收款证据/幂等/审计约束，不用下拉直接将无凭证赠送改为payment_funded，不清洗重写历史。

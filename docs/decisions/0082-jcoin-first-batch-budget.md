# ADR 0082 — JCOIN 第一期100万枚额度

- Status: Accepted
- Date: 2026-09-14
- Task: [GG-083](../tasks/GG-083-jcoin-batch-accumulation.md)
- Extends: [ADR0081](0081-jcoin-batch-accumulation.md)的分批/仅累计结构，只接受首批额度。

## Context and decision

用户明确回复“第一期100万枚，占1%发行量，同意”，随后询问按照刚才公式需要多少平台消费才能发完。第一期锁定1,000,000 JCOIN，占1亿总上限1%、5000万用户回馈池2%，从既有回馈池占用。20%创作安排、分批无期限、另开下一批、仅累计/无兑换/无人民币锚定和9.18起算均不变。

每100有效充值消费积分奖励10枚仍是讨论建议；用户询问按该公式测算不等于已经接受倍率。具体批次边界/退款回收等执行建议仍待接受。

## Consequences

按照建议系数10与现有[100积分/CNY](0063-model-management-and-cent-credits.md)，正常无退款且全部为合格消费时，100万枚需要1000万有效充值消费积分，即10万元消费。此金额仅是合格创作服务消费规模，不能反向标记为币的售价/兑换价或人民币估值。

当前无发行运行时；本决定不授权公开发币、迁移、真实支付或部署。下一步确认倍率与执行规则，再实施消费奖励账本和累计界面。

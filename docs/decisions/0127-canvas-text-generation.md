# ADR 0127 · 画布文本生成与双击编辑

- 日期：2026-10-02
- 状态：已接受（本地源码实现，运行激活单列）
- 任务：[GG-291](../tasks/GG-291-canvas-text-generation.md)

后继ADR0129取代本条取消全退：已预留的用户中断按半价10积分结算，成功20、系统失败0；其余决定保持。见[ADR0129](0129-text-generation-interruption-billing.md)。

后继ADR0130扩展原仅模型的chat：模型旁增加预设菜单，选择后显示可移除标签，隐藏指令由后端解析，允许不填附加内容生成。见[ADR0130](0130-text-generation-presets.md)。

标题与右键新增入口采用“图片生成”“文本编辑”“文本生成”，保留各自编号。文本编辑默认使用箭头光标并可拖动，双击或键盘明确进入编辑；外部操作退出编辑且保留内容。选区、输入和Markdown工具栏只在编辑状态工作。此项取代ADR0124的直接编辑交互，沿用现有正文/标题字号、尺寸柄和端口。

新增独立textGenerator节点，空态同图片生成且中间为文本图标。下方chat只有模型选择及右侧发送/停止，默认claude-opus-5-5，其余精确ID为gemini-3.1-pro-preview、doubao-seed-2.0-pro、gpt-6.1-sol、deepseek-v4-pro。图标使用统一黑灰品牌形状。思考默认high，不新增参数控件。接收文本、图片和视频，输出可编辑Markdown并可继续作为提示词连线；当前生成冻结输入，流式响应按增量显示，生成中不能编辑输出或重复提交，取消/失败保留已显示内容。

浏览器仅调用GoodGood鉴权API，后端复用中转站服务端凭据并统一调用/v1/chat/completions，固定reasoning_effort=high；提供商密钥、上游原始错误与私有素材签名不下发到客户端。图片使用已受权素材原图；视频通过代表帧走同一图文接口，不假设所有模型接受原生video_url，不含音轨解析。素材不重新上传。中转站支持度由真实手验确认，禁止静默切换模型或重发计费调用。

用户确认首版每次固定20积分：服务端预留，成功后结算，失败/取消释放；沿现有个人资金来源和组织预算机制。独立文本记录保存幂等ID、输入快照、结果/状态和积分关系，不复用图片任务或进入真实图片Worker。服务进程中断后的过期请求释放预留，不能悬空扣费。JSON画布契约扩展保存文本生成草稿/结果/历史，旧图文节点继续恢复。新迁移与Web构建/重启是后续运行激活步骤，本轮按用户约定只开发，不执行检查或生产操作。

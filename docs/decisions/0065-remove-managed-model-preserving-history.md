# ADR 0065 — 移除模型目录条目并保留历史

- Status: Accepted
- Date: 2026-09-13
- Task: [GG-056](../tasks/GG-056-banana2-lines.md)
- Extends: ADR 0063 的目录管理与不可变价格/审计边界。

用户要求移除已用于本地测试的试价模型。目录条目已被 append-only 管理审计引用，生成批次、项目和价格版本也需要保持可追溯；不能通过删除这些记录来移除一个选项。

以 `managed_models.archived_at` 表示移除，同时关闭该条目的总启用状态。站长普通列表、创作者目录和新生成受理均排除已归档条目；保留其 ID、名字、线路价格和版本历史。归档在同一个行锁/管理锁事务中更新版本并追加 actor/before/after 审计，不发布新价格版本，不修改已有账本、结果、项目或已受理任务。

只允许站长归档，要求已读取的模型版本以防覆盖并发编辑；缺失/已归档条目和冲突返回可恢复错误。普通保存不能重新使用或恢复已归档 ID。本轮不新增批量删除、历史清理或站长恢复界面，仅为指定条目执行本地归档。生产迁移与目录移除仍需独立发布范围。

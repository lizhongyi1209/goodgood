# ADR 0050 — 仅在本机开放 Seedance 页面实测入口

- Status: Accepted
- Date: 2026-09-12
- Supersedes: ADR 0049 中“浏览器提交入口暂不开放”的本地验证边界；不改变其正式产品边界

## Context

GG-035 已证明 Seedance 两条线路的 O1Key 契约，并完成一次标准线路真实文生视频。站长接下来
需要从现有 GoodGood 创作页面手动实测真实接口，但视频定价、持久任务、积分预留、结果资产与
生产发布尚未确定。直接复用正式图片生成路由会把未定价视频混入现有数据库、队列和资产模型；
把临时 provider 密钥送入浏览器则违反服务端凭据边界。

## Decision

- 增加独立的本地页面实测路由 `/api/video/preview`。只有非 production、请求目标为 loopback、
  `GOODGOOD_LOCAL_SEEDANCE_PREVIEW=true` 且配置了绝对密钥文件路径时可用。
- 路由在服务端读取密钥文件并调用 GG-035 adapter。浏览器只提交现有视频产品参数并取得任务
  ID、状态、进度与最终播放地址；密钥永不进入页面、响应、日志或仓库。
- 页面只提交一次，再按同一任务 ID 轮询；任务结束前禁用再次提交。当前实测入口仅支持无素材的
  文生视频，因为本地 `blob:` URL 与私有资产读取 URL 不是 provider 可访问的公开素材地址。
- 该入口不鉴权、不计价、不写数据库/队列/资产库，所以必须保持本地、显式开启且生产失败关闭。
  页面明确标记“本地实测”和“不写入资产库”。

## Consequences

- 站长可在现有 Chrome 页面验证线路、模型、比例、清晰度、时长和声音的真实提交及视频播放。
- 素材创建、历史素材有效性复检、持久视频任务、计价与资产入库仍须在后续正式产品任务中完成。
- 本地实测成功不代表生产已部署或视频计费、所有权和恢复语义已经完成。

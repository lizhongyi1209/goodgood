# ADR 0084 — JCOIN 一期账本、个人隐私视图与站长计划

- Status: Accepted
- Date: 2026-09-14
- Task: [GG-084](../tasks/GG-084-jcoin-ledger-pages.md)
- Extends: ADR0081—0083；一期100万枚、每100有效充值消费积分2枚及9.18北京时间起算不变。

## Context and decision

用户授权将功能实施到页面，明确个人只需自己的统计/获得记录，不看发行总额度。用户GET /api/jcoin仅返回自己的余额、累计获得/撤回、今日获得和分页记录；/jcoin在原工作区导航。发行总额/回馈池/批次额度/已发剩余/消费规模只进入活动站长的/admin/jcoin与受限POST /api/admin/jcoin/{query,action}，不能先返回给个人再CSS隐藏。

独立JCOIN账本以8位小数最小单位存储。迁移只建库存/第一期草稿，不发行给真实用户；站长开启本期后按已定9.18起算处理，允许晚开启重放起算后可靠证据，不改日期。激活后额度/系数固定；暂停阻止新奖励处理但不阻止退款修正，恢复继续原规则；已发完不重开或自动切批。

专用处理器按原成功结算时间/稳定ID核对充值来源及真实manual支付/历史划拨来源，沙盒/赠送/缺证据不发。混合资金无法逐批证明时保守排除并可查异常。最后一笔至多发剩余额度，持久来源事件唯一；已退款而尚未分发的结算不奖励，事后退款撤回原实际奖励，回收锁定、不退批次发行高水位。个人累计余额无消费/兑换功能，因此退款可直接撤回原币。

分发处理器独立于原消费事务，由Worker定期运行，站长可手动处理；自身事务内原子更新库存/账户/流水/来源，失败重跑不重复发币，奖励处理失败不阻塞原消费/退款。用户数据GET只读。未开始和暂停状态正常展示零/已有余额，不显示个人倒计时或全平台进度。

## Consequences

需要迁移0040、JCOIN服务/合同/页面和隔离SQL验证；权限在UI和服务端分别校验。站长动作需既有管理action header、稳定幂等键和不可变动作审计。

本切片完成第一期生命周期；创作池/企业来源/正式视频和第二期参数管理另行规划，不猜测20%分母或擅自分配未确认池。仅本地实施验证，不包含公开发币、生产迁移、真实收款、provider调用或部署。

# ADR 0136 · 图片元数据副本

- Status: Accepted for GG-327, amended by GG-335/GG-336/GG-344/GG-345; cleanup superseded by ADR0138/GG-341
- Date: 2026-10-03
- Extends: ADR0109 的只读图片标签与 ADR0108 的图片快捷操作

GG-341将清理从本弹框移至「去除AI · 10积分」，执行与计费改由受权服务端，覆盖下方旧本地免费清理描述；参数编辑仍保持。见[ADR0138](0138-paid-image-metadata-cleanup.md)。

用户新增从实拍图片提取参数、写入 AI 图片及清除元数据的图片工具。GG-344按用户要求将快捷工具栏与弹框标题统一为「添加数据」，恢复可用的添加入口；开启依据受权素材能力，独立于裁剪/项目就绪开关，原副本写入校验保持。快捷工具栏提供「添加数据」，使用共享 Radix 弹框与既有白灰样式。打开时读取所选原图并预填，不根据生成提示词虚构相机参数。可从当前图片的实际参考图提取，复制/粘贴结构化参数或手动编辑。

GG-345（2026-10-03）按用户要求进一步简化「添加数据」：取消「从参考图提取」及其选择/读取流程；保留当前图自动预填、复制/粘贴、手动填写和还原。移除所有C2PA状态/验签/失效/水印/外部凭证说明和「清理请使用去除AI」提示，不将底层逻辑暴露到该弹框。底部只留「确认添加」，覆盖原下载副本/保存副本；仍沿原保存路径创建新私有副本和旁置画布节点，不覆盖原图。内部容器识别、普通编辑保留凭证及独立去除AI的处理/计费不改变。

下方GG-335/GG-336为历史决定，用户展示与参考图入口由上述GG-345覆盖。

GG-335（2026-10-03）按用户要求取消「从照片提取」及另选本地照片的入口，覆盖 GG-327 的本地 donor 导入决定。当前目标图仍自动读取；其他图片的参数可通过各自弹框复制后粘贴。实际生成参考图提取保留。AI 生成信息检测本轮只作技术说明，不新增检测入口或外部服务。

GG-336（2026-10-03）扩展现有清除范围，识别 JPEG APP11 中的 C2PA JUMBF Manifest Store，以及 PNG caBX 内容凭证块。弹框只显示文件内凭证数据存在/未发现/无法完整识别，不验证签名、信任链、创作历史或判定 AI/实拍。点击现有「清除元数据」后保存/下载副本，移除可识别的整组 C2PA 分片/块与已有清除范围内的 EXIF/XMP；不将其他 JPEG APP11 内容一概删除。无法确定归属的损坏 JUMBF 数据不宣称已清干净，保留源图并明确失败。普通编辑保留原内嵌凭证字节，但提示编辑可能使凭证失效；不伪造或重新签名。清除只处理文件内数据，不访问/删除远端凭证，不清除像素水印或承诺无法识别 AI。保持 JPEG/PNG 与20MiB范围、原副本路径和现有朝向保护；无需后台、依赖或外部服务。依据 [C2PA 2.4 文件嵌入定义](https://spec.c2pa.org/specifications/specifications/2.4/specs/C2PA_Specification.html#_embedding_manifests_into_non_bmff_based_assets)。

以 JPEG APP1 EXIF 与 PNG eXIf 保存常用相机/镜头/曝光/时间/作者/描述/GPS 字段。表单值属于用户写入的副本参数，生成记录仍保持真实模型与输入。保存或下载才处理文件；始终创建新副本，不覆盖源资产。保存副本复用现有私有上传、本机预览、失败重试及项目同步，不新增数据库字段或后台服务。

清除移除 EXIF（含定位及缩略图）、JPEG XMP/IPTC/注释、PNG 文本/时间类元数据；保留解码与色彩显示所需结构。普通文件只编辑容器，不重压缩像素。若清除旋转 EXIF 会改变照片朝向，先按浏览器解码朝向生成无元数据 PNG 副本，保持视觉方向。仅支持 JPEG/PNG，损坏或不支持的文件明确报错；提取无参数不覆盖已有草稿。

依据 [CIPA EXIF 定义](https://www.cipa.jp/e/std/std-sec.html) 与 [W3C PNG eXIf](https://www.w3.org/TR/png-3/#eXIf)。实现为浏览器内文件处理，不调用模型或外部元数据服务。按当前用户代码交付约定，自动编译、检查与浏览器验收不执行。

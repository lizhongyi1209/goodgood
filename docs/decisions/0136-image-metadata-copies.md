# ADR 0136 · 图片元数据副本

- Status: Accepted for GG-327, amended by GG-335
- Date: 2026-10-03
- Extends: ADR0109 的只读图片标签与 ADR0108 的图片快捷操作

用户新增从实拍图片提取参数、写入 AI 图片及清除元数据的图片工具。快捷工具栏提供「增加元数据」，使用共享 Radix 弹框与既有白灰样式。打开时读取所选原图并预填，不根据生成提示词虚构相机参数。可从当前图片的实际参考图提取，复制/粘贴结构化参数或手动编辑。

GG-335（2026-10-03）按用户要求取消「从照片提取」及另选本地照片的入口，覆盖 GG-327 的本地 donor 导入决定。当前目标图仍自动读取；其他图片的参数可通过各自弹框复制后粘贴。实际生成参考图提取保留。AI 生成信息检测本轮只作技术说明，不新增检测入口或外部服务。

以 JPEG APP1 EXIF 与 PNG eXIf 保存常用相机/镜头/曝光/时间/作者/描述/GPS 字段。表单值属于用户写入的副本参数，生成记录仍保持真实模型与输入。保存或下载才处理文件；始终创建新副本，不覆盖源资产。保存副本复用现有私有上传、本机预览、失败重试及项目同步，不新增数据库字段或后台服务。

清除移除 EXIF（含定位及缩略图）、JPEG XMP/IPTC/注释、PNG 文本/时间类元数据；保留解码与色彩显示所需结构。普通文件只编辑容器，不重压缩像素。若清除旋转 EXIF 会改变照片朝向，先按浏览器解码朝向生成无元数据 PNG 副本，保持视觉方向。仅支持 JPEG/PNG，损坏或不支持的文件明确报错；提取无参数不覆盖已有草稿。

依据 [CIPA EXIF 定义](https://www.cipa.jp/e/std/std-sec.html) 与 [W3C PNG eXIf](https://www.w3.org/TR/png-3/#eXIf)。实现为浏览器内文件处理，不调用模型或外部元数据服务。按当前用户代码交付约定，自动编译、检查与浏览器验收不执行。

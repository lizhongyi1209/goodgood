## GG-311 · 保存弹窗与资产入口（2026-10-02）

用户明确细化保存界面：弹窗标题「保存提示词模板」，下方「模板名称」，移除弹窗内的1:1预览，提交按钮仅为「保存」。取消/保存前景沿GG-310规则，完整内容仍冻结并受权持久保存；资产列表的1:1文字缩略保持。

只有服务端确认保存完整内容后，资产入口显示短暂灰阶接收动效及「已添加到资产」提示，接替仅节点工具栏的成功文字；删除、失败、普通列表刷新不触发，减少动态效果时只给静态提示，不强制打开面板或改变当前筛选。

画布资产面板右上×改为类型筛选图标，单选「全部 / 图片 / 视频 / 音频 / 提示词模板」，对当前文件夹素材生效，图片涵盖生成/上传；文件夹导航与整理身份保持。筛选中的图标用浅灰选中底及可访问当前类型，空结果有明确提示并可恢复全部。面板沿原资产入口切换或Escape关闭，大厅资产页既有筛选保持。这些条款覆盖下方原阶段的弹窗预览和成功提示说明，无后端/迁移或运行变化。

文本编辑节点与文本生成结果单击只选中，名称行上方显示快捷栏，首项“设置模板”；双击或已有Enter/F2入口进入编辑才显示Markdown格式栏。两栏互斥，编辑失焦/取消或取消选中恢复原状态，生成中保留输出锁。空文本生成节点也有首项但禁用保存，不将chat输入或隐藏生成预设误存为结果。

设置模板打开沿用Radix的命名/保存弹窗，冻结当前Markdown和纯文本，默认名取首行。保存完整内容为独立私有文本资产，而非图片截图或浏览器临时状态。保存过程锁定重复提交；同一保存尝试使用稳定UUID并在后端校验内容相同以支持重试。空内容、超出已有编辑器内容边界、失去授权与存储失败均明确失败，保留节点内容，不假报成功。

资产记录按owner/workspace授权，与现有资产组织共用text类型。画布资产栏与资产页显示1:1方形文字缩略，浅灰底/深灰字、固定字号和内距；只裁切溢出预览，完整Markdown/文本仍可查看、下载或拖回画布为独立文本编辑节点。沿现有重命名、文件夹和确认删除能力，保存模板不会触发任何生成或积分消费；后续修改源节点不改变已保存模板。

新增text_assets表与asset_organization类型扩展的迁移源码，不改已有图片/视频/音频记录或原对象。前端只调用GoodGood受权API；列表仅给预览摘要，完整内容按同一受权ID读取，文本以React文本节点显示，不能执行嵌入HTML。删除同时移除整理记录，已放到画布的内容副本保持。

此项扩展ADR0124/0127的工具栏规则及现有媒体资产边界；与ADR0130后端隐藏的文本生成预设是不同功能，不展示或保存其内部指令。按用户约定仅修改源码与回归来源，不编译、验证、运行迁移或启用服务。旧后端无文本API时既有资产照常读取，保存须提示未启用；真实持久保存需后续明确委托更新本地Web及迁移，生产未授权。

# ADR 0072 — 线路整体折扣编辑

- Status: Accepted
- Date: 2026-09-14
- Task: [GG-069](../tasks/GG-069-pricing-discount.md)
- Extends: ADR 0071、0069；人民币与独立线路定价不变。

用户要求整体折扣输入：98表示原价98%（9.8折），80表示8折。定价面板提供1–100整数折扣与“应用折扣”，作用于当前线路全部分辨率、质量和视频两档价格，不影响其他线路。首次应用前价格作为本次编辑基准，后续应用从同一基准计算，100可恢复基准。切换线路保留各自输入/基准/状态。取消关闭丢弃折扣编辑；重新打开以当前已保存价格重新开始，100为默认值。

这是一种批量价格编辑工具：已有owner保存事务持久化最终人民币换算的积分价格和审计快照，不另存长期优惠活动或乘数，不重写历史报价。空白不填补，非法值整体拒绝。精确整数分计算、四舍五入到0.01元；正价最低0.01元，防止折扣产生无效零价。应用只更新可见草稿和试算，保存才生效；不触发生成或扣款。

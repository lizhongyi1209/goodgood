# ADR 0083 — JCOIN 第一期50万元消费规模与系数2

- Status: Accepted
- Date: 2026-09-14
- Task: [GG-083](../tasks/GG-083-jcoin-batch-accumulation.md)
- Extends: [ADR0081](0081-jcoin-batch-accumulation.md)、[ADR0082](0082-jcoin-first-batch-budget.md)。

## Context and decision

用户要求第一期按预计50万元人民币消耗规模分发。第一期额度仍为1,000,000 JCOIN；沿同批固定比例的公式与当前100积分/CNY，50万元有效充值消费为50,000,000积分，因此首期系数确定为每100个有效充值消费积分奖励2枚JCOIN。

`第一期奖励 = 有效充值消费积分 ÷ 100 × 2`

正常无退款、全部符合资格时，5000万有效积分消费对应100万枚奖励。系数10的前次建议由本决定取代；本期不采用档位加成或固定日释放。

50万元是反推系数的消费规模，不是币的人民币售价/价值锚定，不额外设营业额关闭条件。批次仍以100万枚限额发完结束，无截止日期，下一批另行开启；9.18起算、仅累计/无兑换、20%创作保留和总库存不变。

## Consequences

奖励资格仍为正式成功结算的真实充值来源部分，不统计单纯充值到账、赠送/测试、预扣或释放；赠送先用规则不变。支持小额累计：消费1个有效积分对应0.02枚，无需等消费满100积分才奖励。

退款按原奖励反向修正、最后一笔封顶及批间消费的具体执行规则另行确定；50万元是正常消费测算，不能据此承诺存在退款时净消费必然正好为50万元。当前无发行运行时，此决定不授权迁移、公开发行或部署。

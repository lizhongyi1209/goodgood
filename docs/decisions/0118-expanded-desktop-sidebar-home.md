# ADR 0118: PC端展开功能栏与Home入口

- Status: Accepted
- Date: 2026-09-30
- Task: [GG-220](../tasks/GG-220-expanded-sidebar-home.md)
- Supersedes: [ADR0111](0111-workspace-icon-rail.md)的PC端仅图标窄栏。

## Decision

用户要求交给子agent，将左侧功能栏设置为PC端展开，将「创作」改为首页icon，定义为home。

共享大厅在现有720px移动断点以上默认展开为图标加文字侧栏，不新增折叠开关或持久化偏好。首入口使用Lucide Home房屋图标、名称「首页」和home导航标识；点击复用现有主页/创作导航逻辑，已有项目上下文沿用，不新增URL，不改生成器或后端枚举。G品牌及原选中/焦点/权限/账户行为保持。手机布局保留，已有同义主入口更新为首页语义。

仅改共享工作区主页及其侧栏CSS，不改独立画布及画布会话文件，不恢复平台币。白底、黑灰图标、浅灰hover/选中保持。

## Delivery

从verified05e90d2独立建GG-220-home-sidebar，以当前GG-116主页与静态依赖快照形成可编译基线；子agent只编辑app/page.tsx与app/globals.css。根精确回放本任务差异，不能整树合入基线或覆盖GG-219画布缩放工作。UI热更新，无后端/数据/服务/生产操作。

## GG-223 addendum — 展开侧栏不显示额外hover文字（2026-09-30）

用户要求交给子agent，展开模式鼠标hover不再出现额外文字。当前共享侧栏在720px以上始终展开，不存在折叠状态；移除该侧栏的Tooltip包装与provider，常驻名称、aria标签、焦点/选中、账户菜单和轻提示保持。不影响其他功能Tooltip或独立画布，不新增折叠模式/偏好。

## GG-224 addendum — 撤下探索与统一资产集合图标（2026-09-30）

用户要求删除功能栏「探索」，替换资产图标以表达图片、视频、音频和文本等集合。移除无处理函数的探索占位入口；资产使用同一Lucide图标系的LibraryBig资料库标志，保持资产名称、原路径/handler、提醒与权限。不新增文本能力或媒体处理、不改变其他入口/画布/服务。

## GG-227 addendum — 撤下侧栏支持入口（2026-09-30）

用户要求删除左下角帮助和问题反馈入口。仅撤下共享功能栏footer两按钮及闲置引用，保留账户菜单。既有反馈记录、后台处理和其他URL不在本次删除范围；画布与项目区分别由独立任务负责。

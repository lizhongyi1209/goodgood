# ADR 0064 — Banana 选线与分线路规格售价

- Status: Accepted
- Date: 2026-09-13
- Task: [GG-054](../tasks/GG-054-banana-lines.md)
- Extends: ADR 0006、0033、0041、0063 的固定线路/Pro 未开放边界。

用户要求 Banana 系列提供特价、优质、专线，默认特价，允许创作者选择线路并分别定价。产品线路用 `special / quality / dedicated`，与中文标签、上游请求模型 ID 分离；同模型仍只有一个目录条目，不将三条线路冒充三个模型。

Pro 三线路分别请求 `gemini-3-pro-image-c-sp`、`gemini-3-pro-image-c-sd`、`gemini-3-pro-image`。Nano Banana 2 现有特价映射保持不变，新增映射以用户提供或明确可核实的接入资料为准。未确认映射不开放生成，不通过同名后缀猜测线路。

2026-09-13 GG-056 用户补齐 Nano Banana 2 三线路：`gemini-3.1-flash-image-c-sp`、`gemini-3.1-flash-image-c-sd`、`gemini-3.1-flash-image`。映射就绪与目录/线路启用独立；不修改已手动保存的价格或自动启用线路。

站长分别控制每条线路的启用和 1K/2K/4K 人民币每张售价，人民币换算仍为 1 元/100 积分。原价格只沿用至特价；优质/专线初始禁用且未定价，不擅自将低价应用到按量采购的专线。上游 token 费用由平台承担，消费者受理报价固定，不新增实际 token 追扣。Pro 维持原单张输出范围。

目录总启禁与线路启禁分别检查。线路未启用或规格缺价时不接受新任务；新创作默认特价，即使特价禁用也不静默换线。切换线路更新报价；受理事务锁定线路对应不可变价格版本和批次线路，幂等键区分不同线路。已受理任务和重启恢复按原线路执行，不受之后禁用或价格调整影响，不自动回退到另一条线路。

线路贯穿创作状态、草稿、项目、不可变批次输入与结果详情。旧记录线路为空时按旧特价语义读取，不改写旧输入 hash、报价或积分流水；特殊线路价格继续使用原 `standard` 价格作用域，新增两条使用独立作用域。新增迁移只添加配置/状态列，不转换或清空真实数据；生产执行需要独立发布范围。

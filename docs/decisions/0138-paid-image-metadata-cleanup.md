# ADR 0138 · 去除AI与固定积分结算

- Status: Accepted for GG-341, amended by GG-342
- Date: 2026-10-03
- Supersedes: ADR0136的免费本地清理入口；元数据编辑仍按ADR0136。

用户将文件元数据清理独立为图片快捷操作「去除AI」，每次10积分。按钮直接执行；GG-342按用户要求移除旁边的积分文字，价格改在悬停提示与无障碍名称中显示，不新增确认弹框；原元数据弹框移除清理按钮。名称是产品入口，不构成AI检测结论；说明范围为文件内C2PA/EXIF/PNG文本（包括ComfyUI prompt/workflow）及既有XMP/IPTC/注释/时间。不调用模型或外部检测，不去除像素中的SynthID等水印，不访问远端凭证。

服务端从经过身份/工作区/所有权/状态验证的原图读取，复用已存在的二进制容器清理。仅接受JPEG/PNG与20MiB及现有参考图尺寸限制，损坏或无法确定C2PA归属明确失败。普通图片保留原压缩图像流和颜色结构；需EXIF旋转时生成保持视觉朝向的PNG副本。源图保持，新副本进入私有参考资产，可继续下载原始副本字节并在画布相邻添加。

价格由服务端固定为10当前积分，不接受浏览器价格。操作UUID绑定用户、工作区、源图及项目；事务锁串行重复请求，持久记录已提交副本和积分流水。个人账户保留充值来源，企业账户遵守成员预算；预留、结算、ready资产与操作记录同一事务提交，处理/存储/受权/余额失败回滚不收费。同UUID回复丢失后重试返回同副本、不重复扣费；更换输入拒绝。有效图片即使没有可清理字段，明确的一次新操作仍按固定价格收费。

网络断开不等同于撤销已提交收费，浏览器保留请求键用于恢复；身份/画布切换不向新上下文插入旧副本，已成功副本可在原用户资产库找回。后端未启用或迁移缺失时明确不可用，不使用前端余额扣减或免费本地降级。独立0065迁移与Web代码需用户后续授权启用，不重启Worker、不调用生成Provider。本轮按GG-276只写实现与回归来源，不执行自动验证或改变现有运行/数据。

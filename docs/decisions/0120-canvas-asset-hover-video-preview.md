# ADR 0120 — 画布资产 hover 查看入口与节点式视频预览

- Status: Accepted
- Date: 2026-10-01
- Task: [GG-244](../tasks/GG-244-canvas-asset-hover.md)

## Context

GG-238 让图片资产卡的右上查看按钮常驻，视频卡仍只有首帧和下方文字。用户要求图片/视频按钮只在 hover 显示并缩小，去掉视频下方文字，保留 hover 播放，预览样式参考画布视频节点。

## Decision

图片和视频卡采用同一较小的右上查看入口。桌面仅真实 pointer hover 或键盘 focus-visible 显示，普通点击焦点不维持显示；无 hover 设备保留可操作入口。

图片继续使用既有显式图片查看器。视频在卡内 hover 静音循环播放，明确查看时使用既有 Dialog 原语和节点式视频图面：完整真实比例、播放覆盖层与内置时长。去掉卡下「视频」标签，错误/重试和重命名仍可见。

暂停状态保留真实首帧；移出、隐藏页面和卸载暂停；减少动态偏好下不自动播放，仍可由用户明确播放。原拖入、私有资源读取和失败恢复保持。

GG-256 用户确认：资产图面 hover 使用默认光标，右上查看入口 hover 使用抓手光标，但仍是独立点击查看；不触发拖入或改名。生成/上传图片拖到现有文件夹只更新既有组织归属，保留标签与名称；以灰黑靶区、提交呼吸和短暂成功反馈表达整理过程，失败保留原显示并可重试，减少动态偏好取消动画。同文件夹或无效拖入不提交；原拖入画布、文件夹点击和键盘路径保持。见 [任务](../tasks/GG-256-canvas-folder-drop.md)。

## Consequences

取代 DESIGN_SYSTEM 的 GG-238 常驻按钮规则，补充视频卡内播放。hover 不打开浮层或触发上传/生成；不修改画布视频节点、持久化、路由、资产页或生产状态。浏览器与预期验收由用户完成。

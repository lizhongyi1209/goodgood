# ADR 0137 · 平台公告与阅读通知

- 状态：Accepted（2026-10-03，用户本轮功能需求；源码交付，未激活/部署）

2026-10-03入口细化：画布右上仅显示铃铛图标，大厅保留「公告」标签。
无障碍名称、未读圆点、有限到达动效和阅读面板不变。

公告属于平台，不受个人/企业工作区切换过滤。仅启用的真实站长可以管理；所有启用的登录用户可以查看已发布公告和自己的点赞/阅读状态。首版采用标题、Markdown正文、安全HTTP(S)链接；不引入评论、转发、营销订阅或浏览器系统推送。

首页/画布右上角共用入口，收到公告采用短暂灰阶动效和可关闭提示、持续未读标记，不自动打断创作。右侧Sheet沿X式按帖阅读，新公告通过「查看新公告」回最新；移动端全宽，键盘/关闭回焦点及减少动态效果保持。

站长支持草稿、发布更新、置顶/重要标记、撤回、软删除。版本CAS、稳定操作标识及事件记录防止重复发布和覆盖并发更新；重新发布/正文更新产生新的阅读修订。已发布内容只通过明确发布更新改变，撤回从公共流消失，删除先撤回。

实时广播复用现有Redis，SSE只发布公告变动标识，不广播草稿/作者身份/统计。认证、连接数上限、心跳、断线补读、页面隐藏/关闭/身份变化清理必须完整。离线登录补读当前公告和未读状态，不能把暂时离线宣称为实时送达。

点赞按公告/用户去重，取消点赞幂等；观看统计采用实际可视停留后的用户去重阅读人数，刷新与重试不累加，阅读修订决定未读。指标仅受权后台API可读，所有前端不展示点赞数或观看量，公共DTO不携带这些统计。

新增0064仅记录迁移源码，不在真实开发库执行fixture或自动启用Web；源码、运行激活、人工验收与生产部署分别交接。

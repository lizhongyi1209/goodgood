# ADR 0126 · 画布图片裁剪

- 状态：Accepted for GG-280 local implementation
- 日期：2026-10-02
- 任务：[GG-280](../tasks/GG-280-canvas-image-crop.md)；[GG-286默认模式与比例细化](../tasks/GG-286-canvas-crop-action-color.md)
- 扩展：ADR0108画布图片工具与ADR0110媒体框；不改变既有生成任务、计费或全局资产删除行为。

## 决策

1. 单独选中一张可编辑图片时，在图片名/尺寸行上方显示紧凑快捷栏并提供裁剪。图片元信息保持完整；工具栏不随画布缩放变小到不可操作。未完成上传、加载失败、运行中的生成器和视频不进入裁剪。
2. 在原图上编辑选区，显示外侧灰色遮罩、三分网格和可拖拽四角手柄；手柄仅在裁剪模式出现。相邻右侧白色圆角面板显示W/H、比例锁定、可折叠的预设列表；列表滚动，取消/完成动作固定，窄视口调整面板位置。
3. 分组顺序是通用、小红书、抖音、淘宝、拼多多、亚马逊、Instagram、Facebook、TikTok、YouTube、Twitter。不含LinkedIn。分组和预设使用稳定ID，中文名称只做显示；这些是便捷编辑尺寸/比例，不宣称平台政策或自动提交到平台。
4. 宽高来自已解码原图的实际选区像素。新会话默认自由裁剪，比例解锁且不选中预设；自由不是通用分组内的选项，不提供原始比例选项。通用固定比例依次为1:1、3:4、2:3、9:16、4:3、3:2、16:9。锁定时保持比例，自由模式可分别调整，选区始终在图像边界内；预设采用最大可容纳的居中选区，不放大图片，选用后仍可通过比例锁解锁当前选区。切换预设、拖选区或输入尺寸均实时更新遮罩/网格/数值。
5. 仅点击完成时导出真实裁剪File并接入既有私有素材上传。上传图片和独立结果节点替换为新裁剪素材，保留节点身份/位置/连线；生成器结果则创建相邻裁剪图片节点，保留生成器及不可变job/output。原素材记录保留，不覆盖服务器上的原图。不自动发起生成、结算或provider调用。
6. 裁剪会话是临时UI状态，不加入项目JSON。完成后用既有sourceImage节点、ready素材ID及本机待上传File保存恢复，不添加SQL字段、迁移或路由。取消/切页关闭裁剪而不修改图像；读取/导出失败保留可重试选区，上传失败复用既有待上传节点重试。

## 交付边界

用户明确要求agent只修改代码，不执行编译、lint、测试、代码检查或浏览器验收。GG-280交付实现并明确标注未验证；视觉和功能验收交由用户完成。生产未部署。

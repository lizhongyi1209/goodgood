# ADR 0071 — Seedance 双线路定价与 2.5 1080p

- Status: Accepted
- Date: 2026-09-14
- Task: [GG-068](../tasks/GG-068-seedance-line-pricing.md)
- Extends: ADR 0070；更新 ADR 0049 的 2.5 分辨率范围。

用户要求标准/备用分别定价，后续可独立调整折扣后的人民币售价。两条线路复用已确认的 standard/backup 接口映射，不改变上游 ID。复用 managed_models.lines JSON 保存两条 enabled/prices 配置；公开契约使用 videoLines，避免与图片三线路混淆。旧视频单价作为两线路的初始原价读取，第一次保存后独立持久化，根 prices 保持标准线路兼容投影。没有数据库迁移或图片线路转换。

官方价格表已列出 Seedance 2.5 1080p，常规原价无/有参考视频为 77/46 元/百万 token。后台及创作参数都支持 480p/720p/1080p，不支持 4K。Seedance 2.5 在后台和创作模型顺序均优先。参考素材限制、时长和默认 720p 不变。

列表显示两线路价格，删除视频组计费副标题，规格下单位简化为元/百万token。定价编辑器切换线路，未保存输入保留，一次保存提交全部线路。现有视频预览仍无正式账本结算，本任务不做真实付费请求或部署；官方能力不等于已经真实验证每条 O1Key 线路。

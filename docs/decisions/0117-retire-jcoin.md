# ADR 0117: 删除平台币功能

- Status: Accepted
- Date: 2026-09-30
- Task: [GG-217](../tasks/GG-217-remove-jcoin.md)

## Decision

站长要求「交给子agent：将平台币功能删掉」。完整移除 JCOIN 的个人/站长入口、页面、接口及 Worker 自动奖励处理，不再提供发行、暂停、恢复、手动处理、余额和流水查询。旧网页地址退出工作区路由；旧 API 固定返回 no-store 410「功能已移除」，不初始化平台币鉴权、数据库或处理器。

本决定取代 GG-080、GG-082—086 与 ADR 0079—0084 的平台币运行功能。正常积分、充值、积分记录、图片/视频生成结算及退款继续沿用原规则。

历史数据库迁移和平台币账本数据保留为历史证据，本任务不 drop 表、清空数据或撤销已发生记录。不在当前运行数据库或生产执行数据删除。不新增替代奖励功能。

## Delivery boundary

GG-216 画布上传状态任务正在并行。GG-217 从核验过的 GG-214 运行提交 `29e566d` 建独立工作树；子 agent 只能编辑明确分配的非画布文件。当前预览的主页共享文件只能精确合入平台币差异，保留此前 G 图标和所有画布改动；后端运行切换需先核验最新检查点和零活跃任务，不抢占另一个会话的服务操作。
